문제 NP-7 (3SAT → IS)

3-CNF 식에 대해 절당 삼각형 gadget + 모순 리터럴 간선으로 그래프를 구성하고 k를 정하라. 이 식이 satisfiable ⟺ 크기 k의 independent set이 존재함을 두 방향으로 보여라.

힌트 보기

절(clause)마다 삼각형 gadget, 모순 리터럴끼리 간선 — k = 절의 개수. 만족 배정 ⟺ 각 삼각형에서 꼭짓점 하나씩.

정답 보기

개념은 위 힌트 보기에 있음 · 모범답안은 과제 규정에 맞춰 영어

풀이 (English)
  1. Construction: one triangle per clause whose vertices are the clause's literals; add an edge between every pair of contradictory literals (x and ¬x) across triangles; set k = 3 (number of clauses).
  2. (⇒) Given a satisfying assignment (e.g., x = T, y = F, z = F satisfies this formula), pick one true literal from each clause.
  3. No two picked vertices are adjacent: they are in different triangles and cannot be contradictory since both are true.
  4. So they form an IS of size 3.
  5. (⇐) An IS of size 3 must contain exactly one vertex per triangle (at most one per triangle, and 3 triangles).
  6. Setting those literals true is consistent — an IS never contains both a literal and its negation — and makes every clause true.
