문제 SL-6
  1. 방향 그래프의 간선: S→A 7, S→B 2, S→C 3, B→A 3, B→D 6, C→B 1, C→D 8, C→E 4, A→D 1, E→D 1, E→F 7, D→F 2. S에서 Dijkstra를 실행해 노드가 확정되는 순서와 거리를 쓰고, F까지의 최단 경로를 구하시오. [5점]
  2. 음수 간선이 있으면 Dijkstra가 틀릴 수 있다. 3개 노드 반례와 그때 깨지는 불변식을 쓰시오. [3점]
  3. 간선 하나를 비용 0으로 바꿀 수 있다(최대 1개). S에서 F까지 최소 비용을 에 구하는 방법을 설계하고 위 그래프의 답을 쓰시오. [4점]
  4. 음수 간선이 있는 DAG에서 최장 경로를 에 구하는 방법은? [2점]

최단 경로 · 14점

힌트 보기

Dijkstra invariant(확정 노드의 dist는 최종)와 update 규칙; 음수면 Bellman-Ford.

정답 보기

개념은 위 힌트 보기에 있음

풀이
  • (a)

    확정 순서 S B C A D E F

    dist 0 2 3 5 6 7 8

    1. S(0): A=7, B=2, C=3 → B(2): A=5, D=8 → C(3): E=7 (D는 11이라 그대로) → A(5): D=6 → D(6): F=8 → E(7): D는 8이라 갱신 없음, F는 14라 갱신 없음 → F(8).
    2. F 경로: S→B→A→D→F (2+3+1+2=8).
  • (b)
    1. S→A 2, S→B 3, B→ 는 A를 dist 2로 확정하지만 실제 최단은 S→B→A = 1. 깨지는 불변식: '큐에서 꺼낸 노드의 dist는 최단 거리'(꺼낸 뒤 더 짧은 경로가 음수 간선으로 나올 수 있음).
    2. Bellman-Ford 사용.
  • (c)
    1. 노드를 (v,0),(v,1)로 복제. (u,0)→(v,0) 비용 w, (u,0)→(v,1) 비용 0 (할인 사용), (u,1)→(v,1) 비용 w. (S,0) 에서 Dijkstra, 답 min(dist(F,0), dist(F,1)).
    2. 노드 2V, 간선 3E라 같은 시간. 위 그래프: S→A(7)를 0으로 하면 0+A→D 1+D→F 2 = 3.
  • (d)
    1. 모든 간선 가중치의 부호를 바꾸고 DAG 최단 경로(선형화 순서대로 update)를 실행한 뒤 부호를 되돌림. 또는 초기값 −∞, 부등호 반대로. DAG는 음수 간선이 있어도 OK (슬라이드 p.45, 50).
최종 답DAG는 음수 간선이 있어도 OK (슬라이드 p.45, 50)
