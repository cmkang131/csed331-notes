문제 HW-12

가중치(음수 포함)가 있는 DAG에서 s→t 최장 경로의 길이와 최장 경로의 개수를 에 구하는 알고리즘을 설계하고 분석하시오. 간선: s→a 3, s→b 2, a→→d 4, b→c 1, b→d 5, c→d 3, c→t 2, d→

HW3-4 변형 · DAG 최장 경로의 개수 · 5점

힌트 보기

위상 순서대로 DP — 경로 "개수"는 앞선 노드들의 개수 합.

정답 보기

개념은 위 힌트 보기에 있음

풀이
  1. 위상 정렬(s,a,b,c,d,t) 순서로 간선을 update: dist(s)=0, cnt(s)=1, 나머지 →v에서 dist(u)+w > dist(v)이면 dist(v)=dist(u)+w, cnt(v)=cnt(u); 같으면 cnt(v)+=cnt(u).
  2. 정확성: 위상 순서에서 v의 모든 선행노드가 먼저 확정되므로 귀납으로 가 맞음. 시간 결과: dist a=3, b=2, c=3, d=7, t=5; cnt d=2, t=3.
  3. 최장 경로 길이 5, 개수 3 (s-a-d-t, s-b-d-t, s-b-c-t).
최종 답최장 경로 길이 5, 개수 3 (s-a-d-t, s-b-d-t, s-b-c-t)
