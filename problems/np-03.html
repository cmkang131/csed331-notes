문제 NP-3 (NP 소속 증명)

k-Independent Set (결정형): 무방향 그래프 G와 정수 k가 주어질 때 크기 k 이상의 independent set이 존재하는가? 이 문제가 NP에 속함을 certificate와 verifier로 보여라.

힌트 보기

NP 소속 증명의 틀: certificate(증거) 제시 + verifier를 만들고 다항시간임을 보이기.

정답 보기

개념은 위 힌트 보기에 있음 · 모범답안은 과제 규정에 맞춰 영어

풀이 (English)
  1. Certificate: a vertex subset S with |S| = k.
  2. Verifier: check and that no edge of has both endpoints in in time — polynomial in the input size.
  3. A YES instance always has such a certificate, so Set NP.
