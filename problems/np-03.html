범위 미확정 — 10/21 수업에서 NP를 다뤘으면 시험 범위 포함. 근거: 9/7 일정표 슬라이드의 이론 주제 순서가 복잡도 → 재귀 → 그래프 → 그리디 → DP → NP → [중간고사]. 10/20까지 DP까지 진도, 10/21(수)이 시험 전 마지막 수업이라 이날 NP를 다뤘다면 범위에 들어감. 실제 출제 여부는 10/21 수업 내용 확인 필요. 모범답안은 과제 규정(영어 답안)에 맞춰 영어로 작성.

문제 NP-3 (NP 소속 증명)

k-Independent Set (결정형): 무방향 그래프 G와 정수 k가 주어질 때 크기 k 이상의 independent set이 존재하는가? 이 문제가 NP에 속함을 certificate와 verifier로 보여라.

힌트 보기

NP 소속 증명의 틀: certificate(증거) 제시 + verifier를 만들고 다항시간임을 보이기.
