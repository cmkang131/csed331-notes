문제 NP-1 (개념)

P, NP, NP-hard, NP-complete의 정의를 쓰고, 네 클래스의 포함 관계를 설명하라. NP이면서 NP-hard인 문제 모음의 이름은?

힌트 보기

P = 다항시간 결정 · NP = 다항 크기 certificate를 다항시간에 검증 · NP-hard = 모든 NP 문제가 다항 reduce · NP-complete = NP ∩ NP-hard.

정답 보기

개념은 위 힌트 보기에 있음 · 모범답안은 과제 규정에 맞춰 영어

풀이 (English)
  1. P = decision problems solvable in polynomial time.
  2. NP = problems whose YES instances have a polynomial-size certificate verifiable in polynomial time.
  3. NP-hard = every problem in NP reduces to it in polynomial time.
  4. NP-complete NP NP-hard.
  5. NP, and NP-complete NP; if NP then NP NP-complete.
최종 답 NP, and NP-complete NP; if NP then NP NP-complete.
