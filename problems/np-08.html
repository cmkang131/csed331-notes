문제 NP-8 (Knapsack 함정)

0-1 Knapsack의 DP 풀이는 \( O(nW) \) 이다. 이것이 "\( Knapsack \in P \)"를 뜻하지 않는 이유를 입력 크기(input size) 관점에서 설명하라.

힌트 보기

입력 크기는 비트 수 — W는 log₂ W 비트. O(nW)는 입력 크기의 지수 → pseudo-polynomial.

정답 보기

개념은 위 힌트 보기에 있음 · 모범답안은 과제 규정에 맞춰 영어

풀이 (English)
  1. The DP table has \( n \times W \) entries, so the running time is \( O(nW). \)
  2. But \( W \) is given in binary, using only \( \log _{2} W \) bits, so the input size is \( \Theta (n + \log W). \)
  3. \( O(nW) \) is exponential in the input size \( (W = 2^{\log W}). \)
  4. Hence this is a pseudo-polynomial algorithm: it does not place 0-1 Knapsack in P, and it does not contradict the NP-completeness of Knapsack.
