문제 NP-5 (IS ↔ VC)

임의의 그래프 G에서 I가 independent set이면 \( V \setminus I \) 가 vertex cover임을, 그 역도 성립함을 증명하라. 이를 이용해 Independent Set \( \le p \) Vertex Cover를 다항시간 reduction으로 작성하라.

힌트 보기

보집합 관찰: I가 independent set ⟺ V ∖ I가 vertex cover. 같은 그래프에서 k ↦ n − k.

정답 보기

개념은 위 힌트 보기에 있음 · 모범답안은 과제 규정에 맞춰 영어

풀이 (English)
  1. Claim: I is an independent set ⟺ \( V \setminus \) I is a vertex cover.
  2. (⇒) If an edge had both endpoints outside \( V \setminus \) I, both endpoints lie in I, contradicting independence.
  3. (⇐) If two adjacent vertices were both in I, that edge would have no endpoint in \( V \setminus \) I, contradicting the cover.
  4. Reduction: map instance \( (G, k) \) of IS to \( (G, n - k) \) of VC; YES ⟺ YES on the same graph, \( O(1) \) work.
  5. (The same map with \( k \mapsto n - k \) gives VC \( \le p \) IS.)
