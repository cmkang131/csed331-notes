문제 NP-5 (IS ↔ VC)

임의의 그래프 G에서 I가 independent set이면 가 vertex cover임을, 그 역도 성립함을 증명하라. 이를 이용해 Independent Set Vertex Cover를 다항시간 reduction으로 작성하라.

힌트 보기

보집합 관찰: I가 independent set ⟺ V ∖ I가 vertex cover. 같은 그래프에서 k ↦ n − k.

정답 보기

개념은 위 힌트 보기에 있음 · 모범답안은 과제 규정에 맞춰 영어

풀이 (English)
  1. Claim: I is an independent set ⟺ I is a vertex cover.
  2. (⇒) If an edge had both endpoints outside I, both endpoints lie in I, contradicting independence.
  3. (⇐) If two adjacent vertices were both in I, that edge would have no endpoint in I, contradicting the cover.
  4. Reduction: map instance of IS to of VC; YES ⟺ YES on the same graph, work.
  5. (The same map with gives VC IS.)
