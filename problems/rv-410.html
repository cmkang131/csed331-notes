문제 4-10

빈도 a5 b9 c12 d13 e16 f45의 Huffman 트리와 cost.

힌트 보기

가장 작은 둘을 반복 합침. cost = 내부 노드 값의 합 + 총 빈도.

정답 보기

개념은 위 힌트 보기에 있음

풀이
  1. 5+9=14, 12+13=25, 14+16=30, 25+30=55, 45+55=100
  2. 코드 길이: f 1, c·d·e 3, a·b 4
  3. cost = 45·1 + (12+13+16)·3 + (5+9)·4 = 45+123+56 = 224. 검산: 내부노드 합 14+25+30+55 = 124, 총빈도 100 → 124+100 = 224 ✓
최종 답cost 224
