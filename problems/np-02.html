풀이 (English)
  1. (a) True — compose the poly-time reduction A → B with B's poly-time algorithm.
  2. (b) False as stated — A with A NP-complete proves is NP-hard; is NP-complete only if additionally NP.
  3. (c) False — NP-hard problems need not be in NP (e.g., optimization or undecidable variants can be NP-hard).
  4. (d) True — if any NP-complete problem were in P, every problem in NP would be in P, so P = NP.
