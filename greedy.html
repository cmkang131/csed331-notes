Greedy란

해를 조각조각 쌓되, 매 단계에서 가장 확실하고 즉각적인 이득을 주는 조각을 고른다. 지금 상황에서 제일 좋아 보이는 선택 = 직관에 기대는 방식 (예: 지금 이익이 큰 회사의 주식에 투자).

  • 쉬운 쪽 — 설계. DP 같은 다른 틀보다 알고리즘을 떠올리기 쉬움
  • 어려운 쪽 — 그 선택이 정말 최적임을 증명하는 것 + 수행 시간 분석

이 단원의 증명 도구: induction (Breakpoints), cut property와 교환 논증 (MST), 교환 논증 (interval scheduling, Huffman)

Selecting Breakpoints

  • 상황: 고정된 경로를 달리는 여행 (전기차 LA → New York), 완충하면 최대 km, 출발 시 완충
  • 목표: 충전소에서 멈추는 횟수 최소
  • Greedy: 갈 수 있을 때까지 최대한 멀리 간 뒤 충전 — 후보 4개 중 첫 충전소를 고르면 거기서 500 km, 마지막 충전소를 고르면 더 앞선 위치에서 500 km 출발 → 늦게 충전할수록 유리
  • 정당성: 매 단계 뒤에 greedy의 위치가 다른 어떤 해보다 뒤처지지 않음 (induction)

Minimum Spanning Tree

문제: 가장 싼 연결 네트워크

  • 상황: 캠퍼스 건물 6개(A-F)를 광케이블로 연결, 연결마다 연 유지비 (백만 원). 일부 연결을 끊되 건물은 모두 연결된 채로 → 총 유지비 최소
  • cycle이 남아 있으면 그 안의 간선 하나를 지워도 연결 유지 (가중치 양수라 더 싸짐) → 최적해에는 cycle이 없음 → connected + acyclic = tree
MST
비용 최소의 spanning tree (모든 정점을 잇는 tree)
조건
간선은 반드시 주어진 그래프의 것, 간선 수 , 가중치는 모두 양수라 가정
입력 가정
입력은 가중치 있는 연결 무방향 그래프라고 가정. 비연결이면 MST는 없고 Kruskal은 최소 신장 포리스트를 구성, Prim은 각 연결요소에서 재시작해야 전체 포리스트를 얻는다
참고
같은 가중치가 있으면 MST가 여러 개일 수 있으나 합은 같음

Kruskal

빈 그래프에서 시작, 간선을 가벼운 순으로 보며 cycle을 만들지 않으면 추가.

  • 간선 1개, 2개는 cycle이 불가능 → 처음 두 개는 무조건 추가, 세 번째부터 cycle 검사
  • 중간 상태 = 여러 tree의 모임 (forest, 부분해) → 다음 간선 = 서로 다른 두 tree를 잇는 가장 가벼운 간선
