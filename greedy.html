Greedy란

해를 조각조각 쌓되, 매 단계에서 가장 확실하고 즉각적인 이득을 주는 조각을 고른다. 지금 상황에서 제일 좋아 보이는 선택 = 직관에 기대는 방식 (예: 지금 이익이 큰 회사의 주식에 투자).

  • 쉬운 쪽 — 설계. DP 같은 다른 틀보다 알고리즘을 떠올리기 쉬움
  • 어려운 쪽 — 그 선택이 정말 최적임을 증명하는 것 + 수행 시간 분석

이 단원의 증명 도구: induction (Breakpoints), cut property와 교환 논증 (MST), 교환 논증 (interval scheduling, Huffman)

Selecting Breakpoints

  • 상황: 고정된 경로를 달리는 여행 (전기차 LA → New York), 완충하면 최대 km, 출발 시 완충
  • 목표: 충전소에서 멈추는 횟수 최소
  • Greedy: 갈 수 있을 때까지 최대한 멀리 간 뒤 충전 — 후보 4개 중 첫 충전소를 고르면 거기서 500 km, 마지막 충전소를 고르면 더 앞선 위치에서 500 km 출발 → 늦게 충전할수록 유리

  • 정당성 증명(귀납법). 출발점에서 목적지까지의 거리를 , 한 번 충전으로 이동할 수 있는 최대 거리를 라고 하자. 먼저 이면 출발 시 충전 없이 목적지에 도달하므로 greedy는 최적이다.

    이제 이고 목적지에 도달할 수 있는 경로가 존재한다고 하자. 최적해의 충전 위치를 , greedy의 충전 위치를 라고 하자. Greedy는 출발점에서 도달 가능한 가장 먼 충전소를 선택하므로 이다.

    귀납적으로 라고 가정하고 greedy가 아직 목적지에 도달하지 않았다고 하자. 최적해의 다음 충전 위치 이 존재하면 이다. 따라서 greedy가 이내에서 선택하는 가장 먼 충전소 은 을 만족한다. 반대로 이면 greedy는 다음 충전 없이 목적지에 도달하므로 이후의 충전 위치를 정의할 필요가 없다.

    최적해가 번 충전하여 목적지에 도달한다고 하자. Greedy가 그보다 먼저 도착하면 이미 충전 횟수가 회 이하이므로 충분하다. 그렇지 않으면 귀납적으로 이고, 이므로 greedy도 늦어도 번째 충전 후 목적지에 도달한다. 따라서 greedy의 충전 횟수는 최적해의 충전 횟수 이하이다. 최적해가 최소 충전 횟수를 갖는다는 정의에 의해 greedy 역시 최적이다.

    또한 현재 위치 에서 이고, 보다 앞에 있으면서 이하인 충전소가 없다면 어떤 경로로도 다음 충전을 수행할 수 없다. 따라서 이 경우 no solution을 반환하는 것도 정당하다.

문제: 가장 싼 연결 네트워크

Cut Property — MST 정확성의 엔진

가 어떤 MST의 부분집합이고, 를 가로지르는 의 간선이 없다고 하자. 와 사이를 가로지르는 가장 가벼운 간선 에 대해 도 어떤 MST의 부분집합이다.

  • Kruskal에 적용 — 정당성은 두 경우로 나뉜다: 간선 를 가벼운 순으로 검사할 때
    • 서로 다른 연결요소 (검사 조건 find(u) ≠ find(v)): 를 추가하면 두 tree가 하나로 합쳐진다. = 가 속한 tree로 두면 의 간선은 tree 안에만 있어 cut을 안 가로지르고, 이보다 가벼운 간선은 이미 검사했을 때 가로지르는 것이었다면 추가됐을 것 → 가 교차 간선 중 최소 → cut property로 안전
    • 같은 연결요소 (검사 조건 find(u) = find(v)): 두 끝점 사이에 이미 경로가 있어 를 추가하면 cycle이 되므로 버린다
    즉 find(u) ≠ find(v) 검사가 이 두 경우를 가르는 검사다
  • 주의: Kruskal이 B–D 2 (슬라이드 5) 를 버린 건 B, C, D가 이미 연결돼 cycle이 되기 때문이지 안전하지 않아서가 아님.

Union-Find (disjoint sets)

연산과 자료구조

  • makeset(x): x만 든 새 집합 · find(x): x가 속한 집합의 root 노드 (집합의 이름) · union(x, y): 두 집합을 합침
  • : x의 parent 포인터 (root는 자기 자신) · : x를 root로 하는 부분트리의 높이 (슬라이드 정의). 정확히는 union by rank가 유지하는 저장값 — path compression으로 실제 높이가 줄어도 갱신하지 않고, parent를 따라가면 rank는 엄격히 증가한다 (아래 분할 상환 분석이 쓰는 성질)
  • union by rank: rank가 낮은 root를 높은 root 아래에 붙임 → tree를 낮게 유지. rank가 같으면 아무쪽이나 (슬라이드는 ), 새 root의 rank +1. rank가 다르면 높이 그대로

rank의 성질

  1. — root로 올라갈수록 rank는 증가
  2. rank는 root일 때만 바뀌고, non-root가 다시 root가 되는 일은 없음
  3. rank 인 노드는 rank가 그 값으로 정해진 시점(그때는 root)의 부분트리에 노드를 ≥ 개 가짐
    • 귀납: rank 는 rank 둘의 합성 →
    • 승격 시점 기준 주장: path compression으로 자식이 떨어져 나가도 rank는 갱신되지 않으므로 현재 부분트리는 이보다 작을 수 있다
  4. rank 인 노드는 ≤ 개

Path Compression (경로 압축)

find(x)가 지나가는 모든 노드를 root에 직접 연결해 tree를 더 낮게 유지한다. 슬라이드 코드:

find(x):
  if x ≠ π(x) then π(x) ← find(π(x))
  return π(x)

root를 찾는 순회와 압축 순회, 두 번 지나간다 (one-pass 변형으로 path halving: π(x) ← π(π(x))를 따라가며 건너뛰기 — find(x)는 x ≠ π(x)인 동안 π(x) ← π(π(x))로 건너뛰고 x ← π(x)로 전진하는 반복이며, 루트에 닿으면 그 루트를 반환한다).

분할 상환(amortized) 분석 (슬라이드 15-17) — 목표 → 가정과 정의 → 핵심 관찰 → 수식 전개 → 결론 순으로 읽는다.

  1. 목표:

    union by rank만으로는 find가 O(log n)이지만(위 rank의 성질 4), path compression을 더하면 find m번(m은 find 호출 횟수)과 union n−1번을 임의 순서로 실행해도 전체 시간이 O(m log* n)에 묶임(분할 상환)을 보인다.

    개별 find의 비용을 find 자신과 경로 위 노드들에게 나눠 청구하는 예산 방식으로 증명한다.

  2. 가정과 정의:

    분석이 쓰는 성질은 rank의 성질 1 — parent를 따라가면 rank가 엄격히 증가한다.

    먼저 rank 그룹 나누기: rank의 범위 0 ≤ rank ≤ log n을 구간 {k+1, …, 2ᵏ} (슬라이드 15의 그룹 나열 {1}, {2}, {3, 4}, {5, …, 16}, {17, …, 2¹⁶}, … 와 동일;

    경계 k = 0, 1, 2, 4, 16, 65536, …, 다음 경계 = 2^(앞 경계))로 묶으면 실제로 나타나는 양의 rank 그룹 수는 log* n 이하

    (log* n = n에 밑이 2인 로그 log₂를 1 이하가 될 때까지 반복 적용한 횟수; rank가 최대 log n이어도 작은 n에서는 그룹이 다 차지 않을 수 있으므로 등식이 아니라 상한).

    예: log* 65536 = 4 (65536 → 16 → 4 → 2 → 1).

  3. 핵심 관찰: find 경로 위 노드 x는 둘로 나뉜다:
    • A π(x)와 다른 그룹 — 최대 log* n개, find가 지불
    • B 같은 그룹 — x가 지불한다
  4. 수식 전개:

    각 find에는 log* n + O(1) 달러, rank가 구간 {k+1..2ᵏ}인 노드 x에는 2ᵏ 달러를 준다 (한 구간의 노드 수 ≤ n/2ᵏ라 노드에게 주는 총액 ≤ n log* n).

    단 root가 아닌 노드 중 π(x)가 이미 root인 노드는 경로당 최대 하나뿐이라 (root 자체의 종료 검사와 함께) find의 주머니에서 O(1)로 처리하고,

    그 밖의 x는 지불할 때마다 π(x)가 더 rank가 높은 root로 바뀌므로 π(x)가 그룹을 벗어나기 전 최대 2ᵏ번만 지불하고 이후엔 영구히 A가 된다.

    (rank 0인 비-root 노드는 어느 그룹에도 속하지 않지만(그룹은 {k+1,...,2ᵏ}), parent의 rank가 1 이상이라 한 find 경로에 최대 하나뿐이라 별도로 O(1) 처리할 수 있음.

    이처럼 root 자신과 rank 0 주변의 경계 예외는 find마다 O(1)로 처리하므로, 양의 rank 그룹 수 상한과 합쳐 find당 예산 log* n + O(1)이 유지된다.)

  5. 결론:

    find m번 + union n−1번의 임의 순서가 O(m log* n + n log* n) = O(m log* n) (m > n).

    더 정밀한 한계는 Tarjan(1975)의 Θ(m·α(m,n)) — α는 Ackerman 함수의 역함수로, 슬라이드가 쓰는 정의 기준 n < 2⁶⁵⁵³⁶에서 α ≤ 3이라 사실상 상수.

    즉 정렬을 빼면 Kruskal의 union-find 부분은 거의 선형이다.

  1. 허프만 알고리즘의 최적성 증명 — 귀납법. 문자 수가 1개인 경우, 이 증명에서 사용하는 트리 비용의 정의에서는 단일 leaf의 깊이가 0이므로 비용을 0으로 둔다. 부호화 규약으로서 코드 0을 부여한다면 그 실제 부호화 비용은 해당 문자의 빈도와 같지만, 이는 증명에서 사용하는 트리 비용의 정의와는 별개로 취급한다. 따라서 문자 수가 1개인 경우는 이 비용 정의 아래에서 자명하다.

    문자 수가 2개인 경우에는 가능한 prefix-free 코딩 트리가 두 문자를 루트의 두 자식으로 두는 트리뿐이며, 두 leaf의 깊이는 모두 1이므로 비용은 f₁ + f₂이다. 허프만 알고리즘도 이 두 문자를 병합하므로 이 경우에 최적이다.

    문자 수가 3개 이상이라고 하고, 가장 낮은 두 빈도를 f₁ ≤ f₂라 하자. 앞의 Lemma에 따라 f₁, f₂를 형제 leaf로 갖는 최적 코딩 트리가 존재한다. 이 두 leaf와 그 부모를 하나의 leaf z로 축약하고 f(z) = f₁ + f₂로 정의하면, 문자 수가 하나 줄어든 문제를 얻는다. 이때 축약된 문제의 문자 수는 2개 이상이므로, 앞의 경우들과 귀납 가정을 적용할 수 있다.

    원래 트리의 비용은 축약된 트리의 비용에 f₁ + f₂를 더한 값이다. 두 문자를 다시 형제 leaf로 펼치면 각 문자의 깊이가 1씩 증가하기 때문이다. 축약된 트리가 축약 문제의 최적 트리가 아니라고 가정하자. 그러면 더 낮은 비용을 갖는 축약 트리로 바꾼 뒤, z를 빈도 f₁, f₂인 두 형제 leaf로 펼칠 수 있다. 이렇게 하면 원래 문제에서도 비용이 더 낮은 코딩 트리를 얻어 원래 트리의 최적성에 모순된다. 따라서 축약된 트리는 축약 문제의 최적 트리다.

    귀납 가정에 따라 허프만 알고리즘은 축약된 문제를 최적으로 해결한다. 허프만 알고리즘의 첫 단계는 가장 낮은 두 빈도 f₁, f₂를 결합하는 것이므로, 축약 문제에서 얻은 최적 트리를 펼치면 원래 문제의 최적 트리를 얻는다. 따라서 귀납적으로 허프만 알고리즘은 최적의 prefix-free 코드를 생성한다.

single-link -clustering: 점 개를 각각 cluster 하나로 시작 (정점 집합 위의 그래프) → 서로 다른 cluster에 있는 가장 가까운 두 점을 잇는 간선 추가 → 번 반복 → 정확히 개 cluster.

= Kruskal을 연결 성분 개에서 멈춘 것 = MST를 만든 뒤 가장 비싼 개 간선을 지운 것

예제 (연습문제 10 데이터 2, 3, 5, 11, 12, 13, 20). 손계산 8의 슬라이드 수치는 노트에 남아 있지 않아 이 데이터로 대체

정당성: single-link가 max spacing을 달성
  1. 가정과 정의: single-link 결과 C의 spacing을 d라 하자. C의 각 cluster를 잇는 forest의 모든 간선 길이는 d 이하이다.
  2. 핵심 관찰: 다른 k-clustering C*가 C와 다르면, C의 같은 cluster에 속하지만 C*의 서로 다른 cluster에 속하는 두 점이 존재한다.
  3. 수식 전개: 두 점을 잇는 C의 forest 경로에는 C*의 서로 다른 cluster를 잇는 간선 (p,q)가 있다. 이 간선 길이는 d 이하이다.
  4. 결론: C*의 spacing d*는 서로 다른 cluster 사이의 최소 거리이므로 . 따라서 C가 max spacing을 달성한다. ∎
