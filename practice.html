A. 강의와 HW에서 동시에 다룬 알고리즘 — 먼저 도전

  • ☑ 01 · LeetCode 322 Coin Change — HW5 P1 / 동전 DP(동적 계획법) · 거의 동일. 원래 HW의 동전 1·4·6으로도 실행해 보기. 첫 문제 추천
  • ☑ 02 · LeetCode 53 Maximum Subarray — HW2 P5 / 최대 부분배열 · 목표 동일. LeetCode는 풀이법 자유, HW는 분할정복이므로 O(n log n) 분할정복으로 풀어 보기.
  • ☐ 03 · LeetCode 315 Count of Smaller Numbers After Self — HW2 P1 / inversion(인버전) counting · 유사. 반환된 각 인덱스의 수를 합치면 HW의 inversion 개수; 병합정렬 방식으로 풀기.
  • ☐ 04 · CSES Fibonacci(피보나치) Numbers — HW1 P3 / 행렬 거듭제곱 · 거의 동일. O(log n) 알고리즘으로 구현.
  • ☑ 05 · LeetCode 1042 Flower Planting With No Adjacent — HW4 P1 / Greedy(그리디) 색칠 · 거의 동일. 사이트는 d≤3, HW는 일반 최대 차수 d에 대해 d+1색.
  • ☐ 06 · LeetCode 2093 Minimum Cost to Reach City With Discounts (Premium) — HW3 P3 / 상태 확장 Dijkstra(다익스트라) · 유사. HW는 간선 하나를 0으로, LeetCode 2093은 여러 간선을 반값으로 할인 가능(무방향 그래프). Premium 문제라 접근이 안 되면 CSES Flight Discount로 대체.
  • ☐ 07 · LeetCode 2050 Parallel Courses III — HW3 P4 / DAG(방향 비순환 그래프) 최장 경로 · 유사. LeetCode는 양수인 강의별 소요시간(정점 가중치)의 최장 선행 경로, HW는 음수까지 가능한 간선 가중치 최장 경로.
  • ☐ 08 · LeetCode 363 Max Sum of Rectangle No Larger Than K — HW5 P2 / 2차원 최대 부분행렬 · 심화 변형. 사이트에는 합 ≤ K 조건이 추가됨. 원문 먼저 구현한 뒤 도전.
  • ☐ 09 · LeetCode 2378 Choose Edges to Maximize Score in a Tree (Premium) — HW4 P2 / 트리 매칭 · 유사. LeetCode 2378에서 모든 간선 가중치를 1로 두면 최대 매칭 크기 연습 가능. 그 값이 정점 수/2인지 확인(단, Premium). 접근이 안 되면 CSES Tree Matching 활용.
  • ☐ 10 · LeetCode 1489 Critical and Pseudo-Critical Edges in MST(최소 신장 트리) — HW4 P5 / MST 교체 분석 · 관련 심화. *Second-best MST의 최솟값*을 직접 구하는 문제는 아님. 원래 HW는 따로 완성.
  • ☐ 11 · LeetCode 1035 Uncrossed Lines — HW5 P4 / 교차 없는 선분 · 기하 조건 다른 유사 문제. 원 위 현 문제와 다르므로 원문 문제를 따로 구현.
  • 1:1 대체를 찾지 못한 HW5 P3 (좌우·아래 로봇 경로), HW4 P4 (음수 구간 덮기), HW2 P3(b) (볼록 다각형 접선) 등은 유사 문제로 억지 대체하지 않고 원본 HW로 직접 구현하는 것이 정확하다. 다른 문제를 풀었다고 이 HW가 해결된 것으로 간주하면 안 된다.

B. 실제로 중요한 알고리즘 — 과제와 무관해도 필수

  • ☐ DFS(깊이 우선 탐색)/BFS(너비 우선 탐색) — LeetCode 200 Number of Islands · 그래프 탐색과 방문 처리의 기본.
  • ☐ Topological Ordering — LeetCode 210 Course Schedule II · 위상정렬 필수, DAG 응용 전에 권장.
  • ☐ Dijkstra — LeetCode 743 Network Delay Time · Priority Queue + Relaxation. Flight Discount 전에.
  • ☐ Bellman-Ford(벨만-포드) / 음수 사이클 — CSES Cycle Finding · 음수 사이클을 실제로 찾는 문제로, 대응 LeetCode가 없어 CSES 유지.
  • ☐ Floyd-Warshall(플로이드-워셜) — LeetCode 1334 Find the City With the Smallest Number of Neighbors at a Threshold Distance · Floyd-Warshall 거리표로 임계값 안의 도시 수를 계산하는 응용.
  • ☐ Union-Find(유니온-파인드) — LeetCode 1319 Number of Operations to Make Network Connected · Path Compression(경로 압축) + Union, MST 이전에.
  • ☐ Kruskal(크루스칼) / MST — LeetCode 1584 Min Cost to Connect All Points · 최소 신장 트리.
  • ☐ Knapsack(배낭) DP — LeetCode 1049 Last Stone Weight II · 상태 정의와 1차원 DP.
  • ☐ LIS(최장 증가 부분수열) — LeetCode 300 Longest Increasing Subsequence · O(n log n)까지 연습 가능.
  • ☐ Edit Distance — LeetCode 72 Edit Distance · 2차원 DP.
  • ☐ Bitmask DP / TSP(외판원 문제) — LeetCode 847 Shortest Path Visiting All Nodes · TSP 응용, LeetCode 847은 무가중 그래프에서 모든 정점 방문 최단 길이(정점 재방문 허용·출발점 복귀 불필요). 일반 가중치 TSP의 폐회로와 다름.
  • 추천 시작 순서: ① LeetCode 322 → ② LeetCode 53 → ③ LeetCode 315 → ④ LeetCode 743 → ⑤ LeetCode 787(무료) → ⑥ LeetCode 2050. 이후 MST, Floyd-Warshall, TSP로 이동. LeetCode 2093(Premium)는 접근 가능할 때만.

강의별 코딩 문제 로드맵 — 현재 사용 가능한 링크

강의 범위: Efficiency → Recursion → Graph → Greedy → DP. 온라인 문제와 교재 알고리즘의 문제 목표가 다르면 그 차이를 적었다. 정확한 일치 문제가 없으면 링크를 억지로 붙이지 않고 원본 과제 직접 구현으로 표시했다. 아래 체크박스로 진행 상황을 기록하자.

1. 효율성 · 점근표기 · 기하 기초

  • ☐ Fibonacci 재귀 vs DP — LeetCode 509 · 동일한 계산을 다른 복잡도로 구현
  • ☐ Fibonacci O(log n) — CSES Fibonacci Numbers · 매우 큰 n을 O(log n)으로 계산하는 HW1 P3에 가까운 LeetCode 대체가 없어 CSES 유지
  • ☐ CCW 방향 판정 — CSES Point Location Test · CCW의 좌·우·일직선 판정 연습. 같은 조건의 LeetCode가 없어 CSES 유지
  • ☐ Convex Hull — LeetCode 587 Erect the Fence · Graham Scan·Monotone Chain
  • ☐ Big-O·성장률 비교 — 원본 강의/HW 직접 증명 · HW1 P1·P2는 수학적 증명: 코드 저지만으로 충분하지 않음

2. 재귀 · 분할정복 · 선택 · 정렬

  • ☐ 하노이 탑 재귀 — LeetCode 08.06 Hanota (LCCI) · 재귀 호출·base case
  • ☐ Binary Search — LeetCode 704 Binary Search · 탐색 범위 불변식
  • ☐ Merge Sort / Quick Sort — LeetCode 912 Sort an Array · 내장 정렬 대신 직접 Merge Sort 구현
  • ☐ Selection / Quickselect — LeetCode 215 Kth Largest Element in an Array · 정렬 대신 Quickselect 구현
  • ☐ 분할정복 거듭제곱 — LeetCode 50 Pow(x, n) · 빠른 거듭제곱. LC 50은 실수 거듭제곱이며 CSES의 모듈러 거듭제곱과 다름
  • ☐ 행렬 거듭제곱 — CSES Fibonacci Numbers · HW1 P3, O(log n). 직접적인 LeetCode 대체가 없어 CSES 유지
  • ☐ Inversion Counting — LeetCode 315 Count of Smaller Numbers After Self · HW2 P1: 각 위치의 작은 수 개수를 합해 전체 역순쌍 수 계산
  • ☐ Maximum Subarray — LeetCode 53 Maximum Subarray · HW2 P5는 Divide & Conquer 해법을 요구
  • ☐ Closest Pair of Points — CSES Minimum Euclidean Distance · 평면상의 두 점 사이 최근접 쌍 구하기. 동일한 무료 LeetCode 구현 문제가 없어 CSES 유지
  • ☐ 큰 정수 직접 곱셈 — LeetCode 43 Multiply Strings · HW1 P4 자릿수 배열 곱셈 구현(시간 분석 별도)

3. 그래프 탐색 · DAG

  • ☐ DFS/BFS 기초 — LeetCode 200 Number of Islands · DFS/BFS 중 하나로 풀고 다른 방법으로 재구현
  • ☐ Connected Components — LeetCode 547 Number of Provinces · 연결 요소 수를 구하는 문제(인접행렬 입력). DFS forest나 Union-Find로 해결
  • ☐ BFS 최단 경로 — LeetCode 1091 Shortest Path in Binary Matrix · 8방향 격자 BFS로 최단 거리만 계산(경로 복원은 원본 예제에서 별도 연습)
  • ☐ Bipartite — LeetCode 785 Is Graph Bipartite? · 2색칠과 홀수 사이클
  • ☐ Cycle detection — LeetCode 207 Course Schedule · 방향 그래프 순환 존재 여부 판정. 실제 사이클 경로 출력은 별도 구현
  • ☐ Topological Ordering — LeetCode 210 Course Schedule II · Kahn algorithm (in-degree 0)
  • ☐ DAG 의존관계 DP — LeetCode 2328 Number of Increasing Paths in a Grid · 격자에서 값이 증가하는 방향으로 만든 DAG의 경로 수 DP(임의 DAG의 지정 s→t 경로 수와 다름)

4. Dijkstra · Bellman-Ford · Floyd-Warshall · TSP

  • ☐ Dijkstra — LeetCode 743 Network Delay Time · 가장 중요한 heap+relaxation 구현
  • ☐ Dijkstra 응용 — LeetCode 1976 Number of Ways to Arrive at Destination · 최단거리뿐 아니라 그 최단 경로의 개수까지 계산
  • ☐ Bellman-Ford — CSES High Score · 도달 가능한 양의 사이클의 영향까지 검사하는 최장 경로. 무료 LeetCode에서 같은 조건의 문제를 찾지 못해 유지
  • ☐ Negative Cycle — CSES Cycle Finding · Bellman-Ford로 실제 음수 사이클 검출·복원. 직접 대응 LeetCode를 찾지 못해 유지
  • ☐ DAG 최장 경로 — LeetCode 2050 Parallel Courses III · 선수과목 DAG의 최단 완료 시간 = 양수 정점 가중치 최장 경로. HW3 P4의 음수 포함 간선 가중치와 다름
  • ☐ Floyd-Warshall — LeetCode 1334 Find the City With the Smallest Number of Neighbors at a Threshold Distance · Floyd–Warshall로 거리표를 만든 뒤, 임계거리 이내 이웃이 가장 적은 도시를 고르는 응용(거리표 자체를 반환하지 않음)
  • ☐ Floyd 응용 — LeetCode 1334 Find the City With the Smallest Number of Neighbors at a Threshold Distance · Floyd 또는 반복 Dijkstra
  • ☐ Dijkstra 상태 확장 — LeetCode 2093 Minimum Cost to Reach City With Discounts (Premium) · 상태 확장 Dijkstra. 반값 할인 여러 번·무방향 그래프이며 HW의 무료 간선 1개와 다름. Premium이면 CSES Flight Discount로 대체
  • ☐ 최대 k개 간선 제약 — LeetCode 787 Cheapest Flights Within K Stops · Shortest reliable paths와 유사(정거장 수와 간선 수 구별)
  • ☐ Bitmask TSP — LeetCode 847 Shortest Path Visiting All Nodes · 모든 정점 방문 상태(bitmask)의 BFS/DP. 무가중·재방문 허용·복귀 불필요로 일반 TSP와 다름
  • ☐ Hamiltonian DP — LeetCode 980 Unique Paths III · 격자 전체 유효 칸을 정확히 한 번씩 방문하는 경로 수. 일반 방향 그래프의 Hamiltonian 경로 수와 다름

5. Greedy · Union-Find · MST · Huffman(허프만)

  • ☐ 충전소 선택 Greedy — 강의 Selecting Breakpoints(경유지 선택) 직접 구현 · 강의의 최대 주행거리와 정차 최소화 모델 그대로 코딩
  • ☐ Union-Find — LeetCode 1319 Number of Operations to Make Network Connected · 연결 요소 수/여분 간선 기반 네트워크 연결. 유니온-파인드 구현(매 연결 후 결과 출력은 아님)
  • ☐ Kruskal MST — LeetCode 1584 Min Cost to Connect All Points · 좌표의 맨해튼 거리를 가중치로 사용하는 완전그래프 MST(일반 입력 간선 MST와 다름)
  • ☐ Prim(프림) MST — LeetCode 1584 Min Cost to Connect All Points · Prim 또는 Kruskal
  • ☐ Second-Best MST 근접 응용 — LeetCode 1489 Critical and Pseudo-Critical Edges in MST · MST의 critical/pseudo-critical 간선 분류. HW4 P5의 second-best MST 최솟값과는 다름
  • ☐ Interval Scheduling(구간 스케줄링) — LeetCode 435 Non-overlapping Intervals · 종료 시간이 빠른 순으로 정렬. LeetCode는 최대 선택 수가 아니라 제거할 최소 구간 수를 반환
  • ☐ Interval Partitioning(구간 분할) — LeetCode 2406 Divide Intervals Into Minimum Number of Groups · 겹치는 구간을 분리할 최소 그룹 수. LC는 양 끝점을 포함한 닫힌 구간이라 회의실 문제와 경계 처리 차이
  • ☐ Huffman(2진) 비용 합치기 — LeetCode 1167 Minimum Cost to Connect Sticks · 유료 접근 가능성 있음. HW4 P3은 3진으로 직접 바꾸기
  • ☐ Weighted Scheduling 연결 — LeetCode 1235 Maximum Profit in Job Scheduling · Interval greedy(그리디)가 실패하는 가중치 사례·DP
  • ☐ Clustering(군집화) of maximum spacing — LeetCode 1552 Magnetic Force Between Two Balls · 최소 거리 최대화만 유사, 알고리즘은 Kruskal 대신 이분 탐색

6. Dynamic Programming(동적 계획법)

  • ☐ Fibonacci DP — LeetCode 509 Fibonacci Number · Bottom-up / memoization(메모이제이션) 비교
  • ☐ Bit strings(비트 문자열) 인접 1 제한 — 원본 노트 점화식 직접 구현 · S(n)=S(n−1)+S(n−2), 길이 n 유효 비트열의 개수
  • ☐ Maximum Subarray — LeetCode 53 Maximum Subarray · Kadane와 분할정복 각각 연습
  • ☐ LIS — LeetCode 300 Longest Increasing Subsequence · O(n²) DP 후 O(n log n) 버전
  • ☐ Tree Independent Set — LeetCode 337 House Robber III · 트리에서 부모/자식 동시에 선택 금지
  • ☐ Edit Distance — LeetCode 72 Edit Distance · 2차원 DP 표
  • ☐ Subset Sum — CSES Money Sums · 만들 수 있는 모든 부분집합의 합을 출력. LeetCode 416/1049는 합 존재·최적화를 묻는 변형이라 직접 대응이 없어 CSES 유지
  • ☐ 최소 동전 — LeetCode 322 Coin Change · HW5 P1 거의 동일
  • ☐ Matrix chain style 구간 DP — LeetCode 1039 Minimum Score Triangulation of Polygon · 행렬 곱셈 순서와 동일한 형태의 구간 DP, 문제 목표는 다름
  • ☐ Knapsack — LeetCode 1049 Last Stone Weight II · 두 그룹 합의 차이를 최소화하는 subset sum/0–1 knapsack 변형. 전형적 가방 용량/가치 최대화와 다름
  • ☐ Weighted Interval Scheduling — LeetCode 1235 Maximum Profit in Job Scheduling · 정렬 + 이진탐색 + DP
  • ☐ 2D Maximum Subrectangle — LeetCode 363 Max Sum of Rectangle No Larger Than K · HW5 P2 원문보다 어려움: 합이 K 이하여야 한다는 추가 조건
  • ☐ 로봇 격자 최대합 — HW5 P3 직접 구현 · 온라인 저지와 정확히 일치하는 문제 확인 전까지 자체 테스트
  • ☐ TSP / bitmask DP — LeetCode 847 Shortest Path Visiting All Nodes · 방문 집합 DP/BFS. LC 847은 출발점 복귀가 필요 없고 정점 재방문이 가능

HW1~HW5 전체 26문항 / 세부 28항목 대응표 — 살아 있는 링크만

사용자 제공 원본 HW1~HW5의 모든 대문항을 포함하고, HW2 P3·HW5 P4의 (a)/(b)는 별도 표시했다. 원본 과제와 코딩 사이트 문제가 완전히 같지 않으면 일치도를 확인하자.

과제별 특수 변형 — 사이트 문제만 풀면 빠지는 부분

  • HW1 P1·P2·P4: Big-O 증명, 함수 성장률 정렬, 자릿수 곱셈 루프 시간분석은 풀이 코드만 제출해도 연습이 완결되지 않음.
  • HW2 P2·P3(b)·P4·P6: local minimum과 peak는 부호 반전; 접선 O(log n), 일반 k번째, 직사각형 합집합 '경계 출력'은 저지와 다른 부분을 직접 구현.
  • HW3 P2·P5·P6·P7: 가중치 전부 +c 변화 검증, 특수 방향 트리, 간선 추가, 가중치 비내림차순 조건은 독립 구현·증명이 필요함.
  • HW4 P2·P3·P4: Tree Matching은 최대 matching을 출력; 3진 Huffman은 자식 3개씩 결합; 음수 구간 덮기는 1:1 저지 문제 미확인.
  • HW5 P4(a)(b): 원 위 현의 비·전교차 부분집합은 전깃줄(LIS) 문제와 도형 조건이 다르므로 변환과 증명 필요.
  • HW3 P1: LeetCode 2077은 Premium 접근 제한이 있을 수 있으므로, 접근이 안 되면 원문으로 직접 triangle-counting 프로그램을 만들어 테스트하면 됨.
