  • graph : , 노드(vertex) 집합 + 간선(edge) 집합
    • 간선 = 서로 다른 두 노드를 잇는 쌍 (같은 노드끼리는 X)

    • 거리(길이)는 일단 안 봄 → 뒤에서 간선 길이를 붙임
  • 응용 : 관계를 노드와 간선으로 바꾸면 알고리즘을 그대로 씀

  • PageRank : 링크를 받으면 지지표 1개
    • 순위는 링크를 건 페이지들의 PageRank에 따라 재귀적으로 정해짐
    • 링크를 많이 받고, 그 링크가 높은 페이지에서 올수록 높은 순위
    • 사람이 링크를 무작위로 클릭할 때 그 페이지에 도착할 확률

트리

  • tree : connected + acyclic인 무방향 그래프
  • Theorem : 노드 개인 그래프에서 아래 셋 중 둘이면 나머지 하나가 성립
    • (a) connected
    • (b) cycle 없음
    • (c) 간선이 개
  • 성질 : tree ⇔ 모든 노드 쌍 사이에 simple path가 정확히 하나
  • 슬라이드 9 그래프 : , 간선 10개, connected, cycle 없음 → tree
  • 무방향 그래프는 간선 수만 세어도 cycle 여부를 앎 (connected일 때)
    • 간선 → tree, cycle 없음
    • 간선 → cycle 있음
    • 간선 → 연결 불가
  • 방향 그래프는 간선 수로 판단 불가 → 뒤의 DFS(깊이 우선 탐색) back edge(백 엣지)로 판단
unique path 증명
  • tree에서 두 노드 사이 path가 둘이면 두 path의 합집합에 cycle이 생김 → acyclic과 모순
  • 반대로 모든 쌍 사이에 path가 있으면 connected
  • path가 유일하면 cycle이 있을 수 없음 → acyclic
  • 간선 수 은 노드 수에 대한 귀납법 (base : 노드 1개, 간선 0개)

  • 질문 : 시작 노드 에서 도달 가능한 부분은 어디인가

방향 그래프의 DFS

pre/post 번호와 간선 4종류

  • 방향 그래프에서도 DFS 그대로 → 간선을 화살표 방향으로만 따라감
  • DFS 트리의 용어 : root, ancestor(조상), descendant(자손), parent, child
  • pre / post : explore 시작·끝 때의 시계 값 (시계는 시작할 때, 끝날 때 각각 1씩 증가)
  • 슬라이드 예 : 간선 1→2, 1→4, 2→3, 2→4, 3→1, 4→3 (1에서 시작, 이웃은 번호 순)
  • 1 : pre 1, post 8
  • 2 : pre 2, post 7
  • 3 : pre 3, post 4
  • 4 : pre 5, post 6
  • 간선 4종류
간선 종류 판정 시점 pre/post 관계 예
tree DFS가 따라가 발견한 간선 y 미방문 x_pre < y_pre < y_post < x_post 1→2, 2→3, 2→4

  • 간선 분류는 응용마다 쓸모가 다름 (cycle 검사가 대표적)

cycle과 DAG(방향 비순환 그래프)

  • 방향 그래프의 cycle :
  • Property : 방향 그래프에 cycle이 있다 ⇔ DFS가 back edge를 찾는다
    • 어느 노드에서 시작해도 결과는 같음
    • DFS 한 번, 로 acyclic 판정
  • 슬라이드 그래프 : back edge 3→1 → cycle 1→2→3→1
    • 3→1을 빼면 back edge 없음 → acyclic
  • 간선 수로는 판단 불가 (무방향과 다름)
    • 노드 4개, 간선 6개인 cycle 있는 그래프(슬라이드)와 DAG가 둘 다 존재
    • DAG 예 : 1→2, 1→3, 1→4, 2→3, 2→4, 3→4
  • DAG (directed acyclic graph) : cycle 없는 방향 그래프
  • DAG의 성질
    • post 번호의 내림차순으로 나열하면 선형화(linearization)됨
    • 모든 간선은 post 번호가 더 낮은 노드로 향함
    • source(들어오는 간선 없음)와 sink(나가는 간선 없음)가 각각 1개 이상 (여러 개일 수 있음)
  • 슬라이드 그래프에서 3→1을 뺀 DAG
  • 1 : pre 1, post 8
  • 2 : pre 2, post 7
  • 3 : pre 3, post 4
  • 4 : pre 5, post 6
  • 간선마다 post 비교
  • 1→2 : 8 > 7
  • 1→4 : 8 > 6
  • 2→3 : 7 > 4
  • 2→4 : 7 > 6
  • 4→3 : 6 > 4
  • post 내림차순 8, 7, 6, 4 → 선형화 순서 1, 2, 4, 3
    • 간선 5개가 전부 왼쪽 → 오른쪽
    • 이 DAG의 선형화는 이 하나뿐 (2→4, 4→3 때문에 순서 고정)
back edge ⇔ cycle
  • back edge 가 있으면 는 의 조상 → 트리 path + 간선 = cycle
  • 반대로 cycle이 있으면 cycle 위에서 가장 먼저 발견되는 노드 를 잡음
  • cycle의 나머지 노드는 모두 의 자손이 됨 → 로 돌아오는 마지막 간선이 back edge
source가 반드시 존재 (모순)
  • source가 없다고 가정 → 모든 노드에 들어오는 간선이 있음
  • 아무 노드에서 시작해 들어오는 간선을 거꾸로 계속 따라감
  • 노드 수가 유한 → 언젠가 이미 지난 노드에 도착 → cycle
  • DAG라는 가정과 모순 (sink도 같은 방식으로 증명)

시험 포인트

  • 그래프 표현 : 행렬 공간·간선 확인 vs 리스트 공간·확인
  • 무방향에서 차수의 합 = (리스트 길이 합, 행렬의 1의 개수)
  • tree의 Theorem : connected / acyclic / 간선 중 둘이면 나머지 하나
  • 무방향 cycle 판단은 간선 수, 방향 그래프는 간선 수로 불가 → DFS back edge
  • DFS = stack(재귀), BFS = queue, 둘 다
  • DFS 시간 증명 : 각 간선이 정확히 2번 검사됨
  • BFS : 간선은 같은 층 또는 연속한 층, 같은 층 간선이 있으면 홀수 cycle
  • DFS 방문 순서는 이웃을 보는 순서에 따라 달라짐 (트리 유일 X)
  • pre/post로 간선 분류 : tree/forward, back, cross 부등식 표
  • 방향 그래프 cycle ⇔ DFS가 back edge를 찾음 (시작 노드 무관)
  • DAG : post 내림차순 = 선형화, 모든 간선이 post 낮은 쪽으로
  • DAG는 source와 sink가 각각 1개 이상 (모순으로 증명)
  • DFS 트리는 최단 거리를 반영하지 않음, 간선 길이 1이면 BFS가 최단 경로

문제 3

슬라이드 17의 방향 그래프(1→2, 1→4, 2→3, 2→4, 3→1, 4→3)를 3번에서 시작해 DFS(이웃은 번호 순)할 때 pre/post와 간선 종류, cycle 유무를 구하시오.

답
  • 3 → 1 → 2 → 4 순으로 내려감 (3→1, 1→2, 2→4가 tree edge)
  • 2→3 : 3이 스택에 있음 → back, 4→3 : 3이 스택에 있음 → back

문제 4

(a) 연결된 무방향 그래프가 노드 9개, 간선 9개이면 cycle이 있는가. (b) cycle 없는 무방향 그래프가 노드 9개, 간선 7개이면 연결되어 있는가. (c) 노드 4개, 간선 6개인 방향 그래프는 반드시 cycle이 있는가.

답
  • (a) 연결 + 간선 9 → tree가 아님 → cycle 있음
  • (b) tree라면 간선이 8개여야 하는데 7개 → 연결되어 있지 않음 (연결요소 2개)
  • (c) 아님 : 1→2, 1→3, 1→4, 2→3, 2→4, 3→4는 간선 6개인 DAG
  • 방향 그래프는 간선 수가 아니라 DFS back edge로 판단
