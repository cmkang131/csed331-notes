그래프 기초

graph — 노드(vertex) 집합 + 간선(edge) 집합 . 간선은 서로 다른 두 노드를 잇는 쌍 (자기 자신끼리는 X).

  • 좌표·굽은 모양은 무관 — 노드와 연결이 같으면 같은 그래프 (위상만 봄)
  • 간선 길이(거리)는 일단 안 봄 → 뒤에서 가중치를 붙임
  • 응용 — 관계를 노드와 간선으로 바꾸면 알고리즘을 그대로 씀: 웹(페이지/하이퍼링크), SNS(계정/팔로우), 회로(게이트/전선), 내비게이션(교차로/도로 → 최단 경로)
  • PageRank — 링크 1개 = 지지표 1개. 순위는 링크를 건 페이지들의 PageRank에 따라 재귀적으로 결정. 많이 받을수록, 높은 페이지에서 받을수록 순위 ↑. 링크를 따라 이동하는 무작위 서퍼(random surfer) 모델에서 그 페이지를 장기적으로 방문할 확률로 해석한다. 표준 모델은 일정 확률로 링크와 무관하게 임의의 페이지로 이동하는 damping(teleportation)을 포함한다. 단, 이는 개념적 직관이며 구체적인 계산에는 별도의 수식과 가정이 필요하다

교차 그래프 — reduction의 전형

  • 선분(원)마다 노드 1개, 서로 교차하면 간선 — 교차 문제가 그래프 문제로 바뀜
  • 흐름: 원래 문제 → 그래프 문제 → 그래프 알고리즘 → 해를 원래 문제로 되돌림 (재귀 장의 reduction과 같은 패턴)

경로, 사이클, 연결성

  • path — 연속한 두 노드가 모두 간선으로 이어진 노드 열
  • simple path — 노드가 모두 서로 다른 path
  • cycle — 길이 3 이상, , 앞의 개 노드는 서로 다름
  • connected — 모든 노드 쌍 사이에 path가 있음
  • 슬라이드 2 그래프: 5-2-3-7 (simple path O) · 5-1 (간선 없음 → path X) · 5-4-2-5-6 (path O, simple X) · 5-4-2-5 (cycle) · 3-7-8-3 (cycle)
  • 슬라이드 8 그래프: 노드 11개, 연결요소 2개 ({1,…,8}, {9,10,11}). 5→8은 path 있음, 5→10은 없음 → connected X. 그래프가 크면 눈으로 판단 불가 → 탐색 알고리즘이 필요

트리

노드 개인 무방향 그래프에서 아래 셋 중 둘이 성립하면 나머지 하나도 성립:

(a) connected    (b) cycle 없음    (c) 간선이 개

  • tree = connected + acyclic인 무방향 그래프 ⇔ 모든 노드 쌍 사이에 simple path가 정확히 하나
  • 간선 수로 판정할 때 (유한 무방향 그래프): connected이면서 간선이 n−1개이면 tree이다. 간선이 n−1개보다 적으면 connected일 수 없고, n−1개보다 많으면 connected 여부와 무관하게 cycle이 존재한다. 간선이 n−1개라는 것만으로는 부족하고, connected인지까지 확인해야 tree라고 할 수 있다
  • 방향 그래프는 간선 수로 판단 불가 → 뒤의 DFS back edge 유무로 사이클 존재 여부를 판단. 단, back edge가 없다는 사실만으로 방향 그래프가 트리라고 결론 내릴 수는 없다 — 방향 트리의 판정에는 별도의 구조적 조건이 필요하다
unique path 증명 보기
  • tree에서 두 노드 사이 path가 둘이면 두 path의 합집합에 cycle이 생김 → acyclic과 모순
  • 반대로 모든 쌍 사이에 path가 있으면 connected, path가 유일하면 cycle 불가 → acyclic
  • 간선 수 은 노드 수에 대한 귀납법 (base: 노드 1개, 간선 0개)
  • 슬라이드 9 그래프: , 간선 10개, connected, cycle 없음 → tree

DFS

질문 — 시작 노드 에서 도달 가능한 부분은 어디인가. 아이디어 — 안 가 본 방향으로 끝까지 파고, 막히면 직전 노드로 돌아와 계속.

explore(G, v):
    visited(v) = true
    이웃 u마다: visited(u) = false이면 explore(G, u)

dfs(G):
    모든 노드 visited = false
    방문 안 한 노드마다 explore
  • 재귀 호출 = stack (호출 스택이 돌아갈 곳을 기억). visited는 배열, 처음엔 전부 false
  • explore 한 번 = 연결요소 하나만 훑음 (무방향 그래프에서 미방문 정점으로 시작할 때). dfs(G)가 다른 연결요소에서 다시 시작 (슬라이드 8 그래프는 루트 1, 9에서 2번). 방향 그래프에서는 한 번의 explore가 그 정점에서 방향 경로로 도달 가능한 정점들을 방문한다
  • 시간 계산은 관점을 노드에서 간선으로 바꿔 세면 쉬움 — 간선마다 끝점이 2개라 총 번 검사

BFS

에서 가까운 순서대로 층별로 탐색하며 거리 계산. layer 0 = 나, layer 1 = 직접 친구, layer 2 = 친구의 친구, … DFS처럼 끝까지 파지 않고 모든 방향으로 한 단계씩.

층의 정의

  • 이하 두 관찰은 무방향 그래프에서 BFS를 수행할 때 성립한다
  • 관찰 1 — 모든 간선은 같은 층 또는 연속한 두 층의 노드를 이음
  • 관찰 2 — 같은 층의 두 노드를 잇는 간선이 있으면 홀수 길이 cycle이 있음
  • 슬라이드 그래프의 같은 층 간선 (2,3), (4,5), (7,8) → 삼각형 1-2-3, 2-4-5, 3-7-8 (길이 3 = 홀수 cycle)
같은 층 간선 ⇒ 홀수 cycle (증명)
  • 무방향 그래프에서, u와 v가 같은 층 k에 있고 간선 (u, v)가 있다고 하자. 두 노드의 BFS 트리 경로를 거슬러 올라가면 가장 가까운 공통 조상 w가 있고, w는 어떤 층 j에 있다
  • w에서 u로, w에서 v로 내려오는 트리 경로는 각각 층을 하나씩 내려오므로 길이가 k−j이다
  • 두 경로에 간선 (u, v)를 더하면 길이가 2(k−j)+1인 cycle이 되므로, 홀수 길이 cycle이 존재한다

bfs 알고리즘과 큐 추적

bfs(G, s):
    모든 u: dist(u) = ∞;  dist(s) = 0;  Q = [s]

방향 그래프의 DFS — pre/post와 간선 4종류

  • 방향 그래프에서도 DFS 그대로 — 간선을 화살표 방향으로만 따라감. DFS 트리 용어: root, ancestor, descendant, parent, child
  • pre / post — explore 시작·끝 때의 시계 값 (시계는 시작·끝날 때 각각 1씩 증가)
종류뜻판정 시점pre/post 관계예
treeDFS가 따라가 발견한 간선y 미방문1→2, 2→3, 2→4
forward조상 → 자손, tree 아님y는 이미 끝났고 x보다 늦게 시작tree와 같음1→4

  • tree와 forward는 부등식이 같음 → pre/post만으로는 구분 불가 (tree 여부는 탐색 중에 기록)
  • 간선 분류는 응용마다 쓸모가 다름 (cycle 검사가 대표적)

cycle과 DAG

방향 그래프에 cycle이 있다 그래프 전체에 DFS forest를 구성하면 back edge가 발견된다 — 미방문 노드에서 다시 시작해 전체를 탐색하면 시작 순서와 관계없이 cycle이 있을 때 back edge가 발견되고, 없으면 DAG이다. 단, 단일 시작 정점에서만 탐색하면 도달할 수 없는 영역의 cycle은 놓칠 수 있다. DFS 한 번 으로 acyclic 판정.

  • 슬라이드 그래프: back edge 3→1 → cycle 1→2→3→1. 3→1을 빼면 back edge 없음 → acyclic
  • 간선 수로는 판단 불가 (무방향과 다름): 노드 4개·간선 6개인 cycle 있는 그래프와 DAG가 둘 다 존재
  • DAG (directed acyclic graph) — cycle 없는 방향 그래프. 선행 과목·의존 관계 모델

DAG의 성질

  • post 번호의 내림차순 = 선형화(linearization) — 모든 간선은 post 번호가 더 낮은 노드로 향함
  • 유한하고 비어 있지 않은 DAG에서는 source(들어오는 간선 없음)와 sink(나가는 간선 없음)가 각각 1개 이상 존재한다 (여러 개일 수 있음)
  • 예 (3→1 제거): post — 1:8, 2:7, 3:4, 4:6. 간선마다 post 비교: 1→2 (8>7), 1→4 (8>6), 2→3 (7>4), 2→4 (7>6), 4→3 (6>4)
  • post 내림차순 8, 7, 6, 4 → 선형화 1, 2, 4, 3 — 간선 5개가 전부 왼쪽 → 오른쪽. 2→4, 4→3 때문에 순서가 고정되어 이 DAG의 선형화는 이 하나뿐
back edge ⇔ cycle (증명)
  • back edge 가 있으면 는 의 조상 → 트리 path + 간선 = cycle
  • 반대로 cycle이 있으면 cycle 위에서 가장 먼저 발견되는 노드 를 잡음. cycle의 나머지 노드는 모두 의 자손 → 로 돌아오는 마지막 간선이 back edge
source가 반드시 존재 (모순)
  • source가 없다고 가정 → 모든 노드에 들어오는 간선이 있음
  • 아무 노드에서 시작해 들어오는 간선을 거꾸로 계속 따라감 → 노드 수가 유한하므로 언젠가 이미 지난 노드에 도착 → cycle → DAG라는 가정과 모순 (sink도 같은 방식)

  2. (b) cycle 없는 무방향 그래프가 노드 9개, 간선 7개이면 연결되어 있는가
