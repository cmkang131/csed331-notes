2. 재귀 · 분할정복 · master theorem(마스터 정리)

T(n)=aT(n/b)+O(nᵈ): d>log_b a → O(nᵈ), d=log_b a → O(nᵈ log n), d<log_b a → O(n^{log_b a})

# 문제 풀이
1 T(n)=2T(n/2)+n a=2,b=2,d=1, log_b a=1 = d → O(n log n)
2 T(n)=4T(n/2)+n log₂4=2 > d=1 → O(n²)
3 T(n)=3T(n/2)+n² log₂3=1.585 < d=2 → O(n²)
4 T(n)=T(n/2)+n log₂1=0 < d=1 → O(n)
5 T(n)=T(n−1)+n master 불가(T(n/b) 꼴 아님). 펼치면 n+(n−1)+…+1 = n(n+1)/2 = Θ(n²)
6 T(n)=2T(n−1)+1, T(0)=0 (Hanoi) 펼치면 T(n)=2ⁿ−1 = Θ(2ⁿ). 이동 횟수 2ⁿ−1
7 원소 1000개 정렬 배열의 binary search 최악 비교 횟수 ⌊log₂1000⌋+1 = 9+1 = 10
8 정렬된 6개 배열에 quicksort(맨 끝 원소 pivot). 비교 횟수와 Big-O는? n(n−1)/2 = 15번, O(n²) (매번 r=1 또는 n, T(n−1)+O(n))
9 Karatsuba가 곱셈을 3번만 쓰는 이유와 시간 x_L y_R+x_R y_L = (x_L+x_R)(y_L+y_R)−x_L y_L−x_R y_R. T(n)=3T(n/2)+O(n) → O(n^{log₂3})≈O(n^1.585)
10 Strassen의 점화식과 결과 곱 7번 + 덧뺄셈 O(n²): T(n)=7T(n/2)+O(n²), log₂7=2.807>2 → O(n^2.807). 4블록 분할만 하면 곱 8번 → O(n³)
11 S={5,2,9,2,7,1,8}, selection(S,4)를 v=5로 한 번 실행 S_L={2,2,1} (3개), S_v={5} (1개). |S_L|=3 < 4 ≤ 3+1 → 답 v=5. (정렬하면 1,2,2,5,7,8,9 → 4번째 5 ✓)
12 median of medians에서 블록 크기를 3으로 하면? 재귀 크기 합 n/3+2n/3=n → 등비합이 안 줄어 O(n log n). 5이면 n/5+7n/10=9n/10<n → O(n)
13 Closest pair 띠(strip)에서 y 순서로 몇 개 뒤까지 비교하나? 왜? 11개. 띠 폭 2δ × 높이 δ를 변 δ/2 칸 4열×3행=12칸으로 나누면 칸당 점 ≤1개 → |i−j|≥12면 거리 ≥δ

3. 그래프 · 탐색 · 최단 경로

DFS(깊이 우선 탐색)/BFS(너비 우선 탐색) O(V+E), Dijkstra(다익스트라) O((V+E)log V) 양수 간선, Bellman-Ford(벨만-포드) O(VE), Floyd-Warshall(플로이드-워셜) O(n³)

# 문제 풀이
1 무방향 연결 그래프에 n=7, m=6. tree인가? m=8이면? m=n−1=6 → tree. m=8>n−1 → cycle 존재. (방향 그래프는 간선 수로 판단 불가, DFS back edge(백 엣지))
2 방향 그래프에서 cycle 판정 방법과 시간 DFS 중 back edge (y_pre<x_pre<x_post<y_post)를 만나면 cycle. O(V+E)
3 간선 A→B, A→C, B→D, C→D, D→E. topological order 모두? post 내림차순. 가능한 순서: A,B,C,D,E / A,C,B,D,E (B와 C는 순서 자유)
4 Dijkstra 추적: A→B 4, A→C 2, B→C 3, C→B 1, B→D 2, B→E 3, C→D 4, C→E 5, E→D 1. A에서 E까지 최단 거리와 경로 A(0): B=4,C=2 → C(2): B=3,D=6,E=7 → B(3): D=5,E=6 → D(5), E(6). 거리 6, 경로 A→C→B→E (2+1+3)
5 Dijkstra가 음수 간선에서 틀리는 예를 하나 s→a 2, s→b 3, b→a −2. Dijkstra는 a(2)를 먼저 확정하지만 실제 dist(a)=3−2=1. 확정 후 갱신 불가라서 틀림 → Bellman-Ford
6 Bellman-Ford는 몇 라운드? negative cycle(음수 사이클) 판별은? 모든 간선 update를 |V|−1번. |V|번째 라운드에도 dist가 줄면 negative cycle. 시간 O(VE)
7 V=1000, E=1500일 때 Dijkstra에 array와 binary heap 중 무엇이 유리한가 array O(V²)=10⁶, heap O((V+E)log V)≈2500·10≈2.5·10⁴ → heap (E가 V 수준이면 heap, V² 수준이면 array)
8 DAG(방향 비순환 그래프)에서 longest path를 구하는 방법과 시간 선형화 순서대로 나가는 간선을 update, 부등호를 뒤집고 초기값 −∞. O(V+E), 음수 간선도 OK
9 Floyd-Warshall 점화식과 시간, 공간 dist(i,j,k)=min{dist(i,k,k−1)+dist(k,j,k−1), dist(i,j,k−1)}, k가 가장 바깥 루프. O(n³), 표 하나 덮어쓰면 O(n²)
10 DFS tree의 깊이가 최단 거리인가? 최단 거리가 필요하면? 아니오. BFS (간선 길이 1일 때 dist=최단 거리). 연결요소·cycle은 DFS
11 BFS에서 같은 층 두 노드를 잇는 간선이 있으면 무엇이 보장되나 홀수 길이 cycle이 존재
12 TSP(외판원 문제) 비트마스크 DP(동적 계획법)의 부분문제 수와 시간 C(S,j): O(n·2ⁿ)개 × 칸당 O(n) = O(n²2ⁿ). (n−1)!보다 작지만 지수

4. 그리디 · MST(최소 신장 트리) · Union-Find(유니온-파인드) · 스케줄링 · Huffman(허프만)

증명 도구: induction(귀납법), cut property(컷 성질), 교환 논증

# 문제 풀이
1 간선 A-B 1, A-C 2, B-C 3, C-D 4, B-D 5, D-E 1, C-E 6 에 Kruskal(크루스칼) 실행. MST 비용은? 정렬: A-B1 추가, D-E1 추가, A-C2 추가, B-C3 버림(cycle), C-D4 추가(집합 1개) → 합 1+1+2+4 = 8. 이후 B-D5, C-E6 버림
2 위 그래프에서 MST는 유일한가 가중치가 같은 간선은 A-B와 D-E뿐이고 둘 다 선택됨, 선택이 갈리는 지점이 없어 유일. 일반적으로 같은 가중치가 있으면 MST가 여러 개일 수 있음
3 Kruskal과 Prim(프림)의 시간 둘 다 O(E log V) (Kruskal은 정렬+union-find, Prim은 binary heap). log E ≤ 2 log V
4 cut property를 말하라 X가 어떤 MST의 일부이고 S를 X의 간선이 가로지르지 않으면, S와 V∖S 사이 최소 간선 e에 대해 X∪{e}도 어떤 MST의 일부
5 union by rank의 효과: rank k인 root의 tree 크기와 높이 노드 ≥2ᵏ개 → 높이 ≤ log n, find·union O(log n)
6 log*16, log*65536 log 16=4, log 4=2, log 2=1 → 3번. 65536 → 16 → 4 → 2 → 1 → 4번
7 구간 [1,4),[3,5),[0,6),[5,7),[3,9),[5,9),[6,10),[8,11),[8,12),[2,14),[12,16) 에서 최대 compatible 집합 (earliest finish time) 종료 순 정렬 후: [1,4) 선택 → [5,7) (s=5≥4) → [8,11) (s=8≥7) → [12,16) (s=12≥11). 크기 4
8 earliest start time greedy(그리디)가 틀리는 예 L[0,9) 하나 vs a[1,2) b[3,4) c[5,6) d[7,8). earliest start는 L(1개), 최적은 4개
9 위 11개 구간을 최소 강의실로 나누려면 몇 개? (interval partitioning) depth=한 시각에 겹치는 최대 구간 수=6 (시각 8: [3,9),[5,9),[6,10),[8,11),[8,12),[2,14)) → 강의실 6개. 시작 시각 순 greedy의 결과 = depth
10 빈도 a5 b9 c12 d13 e16 f45 의 Huffman 트리와 cost 5+9=14, 12+13=25, 14+16=30, 25+30=55, 45+55=100. 코드 길이 f1, c·d·e 3, a·b 4. cost=45·1+(12+13+16)·3+(5+9)·4=45+123+56=224 검산: 내부노드 합 14+25+30+55=124, 총빈도 100 → 124+100=224 ✓
11 Interval scheduling earliest finish의 최적성 증명 핵심 교환 논증: greedy가 r번째까지 최적과 같으면, f_{i_{r+1}} ≤ f_{j_{r+1}} 이므로 최적의 (r+1)번째를 greedy의 것으로 바꿔도 feasible
12 Selecting breakpoints: 연료 용량 C일 때 greedy 규칙 현재 위치 x에서 x+C 이내 가장 먼 충전소까지 가서 충전. 그 충전소가 x 자체면 no solution. O(n)

5. 동적 계획법

1) 부분문제 정의 2) 점화식 3) 채우는 순서(DAG) 4) 답 위치와 시간

# 문제 풀이
1 SNOWY → SUNNY 의 edit distance와 table 답 3. 마지막 행: [5,4,4,3,3,3]. 점화식 E(i,j)=min{E(i−1,j)+1, E(i,j−1)+1, E(i−1,j−1)+[a_i≠b_j]}. 시간 O(mn)
2 knapsack(반복 불가) W=11, (w,v)=(1,1),(2,6),(5,18),(6,22),(7,28). 최대 가치 답 40 (무게 5+6=11, 18+22). 마지막 행 K[5][11]=40, K[4][11]=40. 점화식 K(i,c)=max{K(i−1,c), K(i−1,c−w_i)+v_i}, 시간 O(nW) (pseudo-polynomial)
3 LIS(최장 증가 부분수열): [3,1,4,1,5,9,2,6] L=[1,1,2,1,3,4,2,4], 최대 4 (예: 1,4,5,9 또는 3,4,5,9 또는 1,4,5,6). L(i)=1+max{L(j): j<i, a_j<a_i}, O(n²)
4 최대 연속 부분합: [−2,1,−3,4,−1,2,1,−5,4] S(i)=max{a_i, S(i−1)+a_i}: [−2,1,−2,4,3,5,6,1,5], 답 6 (4,−1,2,1). O(n)
5 길이 n 이진 문자열 중 '00'이 없는 것의 수 S(n)=S(n−1)+S(n−2), S(1)=2, S(2)=3 → S(3)=5, S(4)=8 (Fibonacci(피보나치) 꼴)
6 chain matrix: A(10×30) B(30×5) C(5×60). 최소 곱셈 횟수와 순서 (AB)C = 10·30·5+10·5·60 = 1500+3000 = 4500. A(BC) = 30·5·60+10·30·60 = 9000+18000 = 27000. 답 4500. 일반 O(n³), 구간 DP, 길이 순으로 채움
7 트리의 independent set DP 점화식 I(v)=max{ Σ_children I(c), 1+Σ_grandchildren I(g) } (또는 v 포함/미포함 두 값). O(n)
8 subset sum: S={3,5,7,8}, target 12 가능한가 5+7=12 가능. T(i,t)=T(i−1,t) ∨ T(i−1,t−a_i), O(n·target)
9 weighted interval scheduling 점화식 job을 종료 시각 순 정렬, p(j)=j와 compatible한 가장 큰 i. OPT(j)=max{OPT(j−1), v_j+OPT(p(j))}. 정렬 O(n log n) + O(n)
10 DP의 시간 = ? (부분문제 수) × (칸당 계산 시간). 예: edit distance O(mn), chain matrix O(n³)=O(n²)칸×O(n), TSP O(n²2ⁿ)
