Q1

(10 points) Show that n! = 2Θ(n log n) .

한국어 풀이 보기

표기 해석. 원문 HTML에서는 지수 표기가 평문처럼 보이지만, 통상적인 의도인 n! = 2Θ(n log₂ n)를 증명한다.

1. 로그를 취한다. log₂(n!) = ∑k=1n log₂ k 이다.

  1. 상한: 모든 k ≤ n에 대해 log₂ k ≤ log₂ n이므로 log₂(n!) ≤ n log₂ n.
  2. 하한: n ≥ 4에서 k = ⌈n/2⌉, …, n인 항은 적어도 n/2개이고 각각 log₂(n/2) 이상이다. 따라서 log₂(n!) ≥ (n/2) log₂(n/2) ≥ (n/4) log₂ n.

그러므로 log₂(n!) = Θ(n log n)이고, 양변을 밑이 2인 지수로 되돌리면 n! = 2Θ(n log n)이다. Stirling 근사는 필요하지 않다.

Q2
(30 points) Design an algorithm for the following problem using a divide-and-conquer approach. Given
a list L of n integers, find a pair (i, j) of indices that maximizes L[i] + L[i + 1] + ... + L[j]. Then analyze
the running time of your algorithm.
한국어 풀이 보기

핵심 아이디어. 최적의 비어 있지 않은 연속 부분 배열은 왼쪽 절반 안, 오른쪽 절반 안, 또는 중점을 가로지르는 경우 중 하나다. 중점을 가로지르는 최적 구간은 왼쪽 절반의 최대 접미사와 오른쪽 절반의 최대 접두사를 붙여 얻는다.

MAX-SUBARRAY(L, lo, hi):
    if lo == hi:
        return (L[lo], lo, hi)
    mid = floor((lo + hi) / 2)
    A = MAX-SUBARRAY(L, lo, mid)
    B = MAX-SUBARRAY(L, mid + 1, hi)

    bestLeft = -infinity; sum = 0
    for i = mid downto lo:
        sum = sum + L[i]
        if sum > bestLeft:
            bestLeft = sum; leftIndex = i

    bestRight = -infinity; sum = 0
    for j = mid + 1 to hi:
        sum = sum + L[j]
        if sum > bestRight:
            bestRight = sum; rightIndex = j

    C = (bestLeft + bestRight, leftIndex, rightIndex)
    return the tuple with largest sum among A, B, C

-infinity로 초기화하므로 모든 원소가 음수여도 빈 구간을 반환하지 않는다. 동률이면 어느 최적 구간을 반환해도 된다.

정당성. 임의의 최적 구간은 중점을 기준으로 위 세 경우 중 정확히 하나에 속한다. 재귀 호출은 첫 두 경우의 최적해를 구하고, 양쪽을 모두 사용하는 경우에는 왼쪽 접미사와 오른쪽 접두사의 합이 최대가 되도록 선형 탐색한다. 따라서 세 후보 중 최댓값이 전체 최적해다.

시간·공간. 교차 구간 계산은 각 재귀 노드에서 O(n)이고, T(n) = 2T(n/2) + O(n) = O(n log n)이다. 인덱스 범위를 사용하고 입력을 복사하지 않는 구현의 보조 공간은 재귀 스택 O(log n)이다.

Q3
(30 points) Describe a linear-time algorithm for partitioning a directed graph into strongly connected
components. You do not need to prove the correctness/time complexity of the algorithm.
한국어 풀이 보기

Kosaraju 알고리즘.

  1. 원래 그래프 G에서 모든 정점을 대상으로 DFS를 수행한다. 각 정점의 DFS가 끝나는 순간 정점을 종료 순서 목록에 추가한다.
  2. 모든 간선의 방향을 뒤집어 전치 그래프 Gᵀ를 만든다.
  3. 첫 번째 DFS의 종료 시각이 큰 순서대로 정점을 살펴본다. 아직 방문하지 않은 정점에서 Gᵀ의 DFS를 시작하고, 그 DFS가 방문한 정점 집합 하나를 하나의 강연결 성분으로 출력한다.

왜 성립하는가(요지). 강연결 성분들을 축약한 응축 그래프는 DAG다. 첫 DFS의 종료 순서는 서로 다른 성분 사이의 도달 관계를 정렬하는 성질이 있고, 전치 그래프에서 그 역순으로 시작하면 각 DFS가 아직 출력하지 않은 다른 성분으로 넘어가지 않고 하나의 성분을 모은다.

시간·공간. DFS 두 번과 전치 그래프 구성이므로 시간은 O(|V| + |E|), 전치 그래프와 방문/종료 순서 저장을 포함한 공간은 O(|V| + |E|)이다. 문제에서 증명을 요구하지 않더라도 알고리즘과 선형 시간 근거를 함께 쓰면 충분하다.

Q4
(30 points) Prove or disprove the following: For an edge-weighted undirected graph G = (V, E), a
minimum spanning tree of G is unique if the edge weights are all distinct.
한국어 풀이 보기

명제: 참이다. 그래프가 연결되어 MST가 존재한다고 가정한다. 서로 다른 두 MST T₁ ≠ T₂가 있다고 가정하고 모순을 보인다.

  1. 대칭차 T₁ △ T₂에서 가장 가벼운 간선을 e라 하고, 이름을 바꾸어 e ∈ T₁ \ T₂라 하자.
  2. T₂에 e를 추가하면 유일한 사이클이 생긴다. 그 사이클에는 T₂ \ T₁에 속하는 간선 f가 적어도 하나 있어야 한다. 그렇지 않으면 사이클의 나머지 경로와 e가 모두 T₁에 있어 T₁에 사이클이 생기기 때문이다.
  3. e는 대칭차에서 가장 가벼운 간선이고 모든 간선 가중치가 서로 다르므로 w(f) > w(e)다. 따라서 T₂ + e − f는 T₂보다 가벼운 스패닝 트리다.

이는 T₂가 MST라는 사실과 모순이다. 따라서 MST는 유일하다. 가중치가 모두 다르다는 조건은 교환 단계에서 엄격한 부등식이 나오도록 보장한다.

시간·공간. 증명 문제이므로 알고리즘 복잡도 분석은 해당하지 않는다.
