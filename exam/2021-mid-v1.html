· 같은 학기 중간고사가 두 버전으로 전해진다. version 2와 문제가 다르므로 둘 다 보존한다.

Q1

(10 points) Show that n! = 2Θ(n log n) .

Q2
(30 points) Design an algorithm for the following problem using a divide-and-conquer approach. Given
a list L of n integers, find a pair (i, j) of indices that maximizes L[i] + L[i + 1] + ... + L[j]. Then analyze
the running time of your algorithm.
Q3
(30 points) Describe a linear-time algorithm for partitioning a directed graph into strongly connected
components. You do not need to prove the correctness/time complexity of the algorithm.
Q4
(30 points) Prove or disprove the following: For an edge-weighted undirected graph G = (V, E), a
minimum spanning tree of G is unique if the edge weights are all distinct.
