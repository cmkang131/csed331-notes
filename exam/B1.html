핵심: 5개씩 묶어 각 묶음의 median 을 구하고, 그 median 들의 median 을 pivot 으로 쓰면 양쪽이 적어도 개씩 보장된다.

정답 보기
  1. Select(L, k):
  if |L| <= 5: sort L, return k-th
  split L into groups of 5; m_i = median of group i
  x = Select({m_i}, ceil(|{m_i}|/2))       // median of medians
  L1 = {a < x}, L2 = {a = x}, L3 = {a > x}
  if k <= |L1|: return Select(L1, k)
  if k <= |L1|+|L2|: return x
  return Select(L3, k-|L1|-|L2|)
