Q1

(10pts) You are given an infinite array A[·] in which the first n cells contain integers in sorted order and the rest of the cells are filled with ∞. But you are not given the value of n. Assume that the implementation of the array data type in your programming language returns the error message ∞ whenever elements A[i] with i > n are accessed. Describe an algorithm that takes an integer x as input and finds a position in the array containing x, if such a position exists, in O(log n) time.

Q2

(10pts) A contiguous subsequence of a list S is a subsequence made up of consecutive elements of S. For instance, if S is

5, 15, -30, 10, -5, 40, 10,

then 15, -30, 10 is a contiguous subsequence but 5, 15, 40 is not. Give a linear-time algorithm for the following task:

Input: A list of numbers, a1, a2, …, an. Output: The contiguous subsequence of maximum sum (consisting of at least one element).

Q3

(10pts) Let us define a multiplication operation on three symbols a, b, c according to the following table; thus ab = b, ba = c, and so on. Notice that the multiplication operation defined by the table is neither associative nor commutative.

Find an efficient algorithm that examines a string of these symbols, say bbbbac, and decides whether or not it is possible to parenthesize the string in such a way that the value of the resulting expression is a. For example, on input bbbbac your algorithm should return yes because ((b(bb))(ba))c = a.

Multiplication table (rows = left operand, columns = right operand):

| | a | b | c |
|---|---|---|---|
| a | b | b | a |
| b | c | b | a |
| c | a | c | c |
Q4

(10pts) An edge of a network is called a bottleneck edge if increasing its capacity results in an increase in the maximum flow. Give an efficient algorithm to identify all bottleneck edges in a network. (Hint: Examine the residual graph returned by Ford-Fulkerson algorithm.)

Q5

In 3Sat the input is a set of clauses, each with three or fewer literals, for example

(x̄ ∨ y ∨ z̄)(x ∨ ȳ ∨ z)(x ∨ y ∨ z̄)(x̄ ∨ ȳ),

and the aim is to find a satisfying truth assignment. In Independent Set the input is a graph and a number g, and the problem is to find a set of g pairwise non-adjacent vertices. - (a) (5pts) Explain a polynomial time reduction that maps an instance S of 3Sat to an instance I of Independent Set. - (b) (5pts) From the construction above, prove the following statement.

> There is an independent set of g vertices for S if and only if there is a satisfying assignment for I. (원문 그대로 — S 와 I 의 역할이 문장에서 뒤바뀐 것으로 보이나 추정 수정하지 않음 [sic])

Q6

(10pts) In the Euclidean Minimum Steiner Tree problem, the input consists of a complete graph G = (V, E) in the plane with Euclidean distance duw between all pairs of nodes, and a distinguished set of terminal nodes V' ⊆ V. The goal is to find a minimum-cost tree that includes the vertices V'. This tree may or may not include nodes in V ∖ V'.

Consider the algorithm that ignores the non-terminal nodes and simply returns the minimum spanning tree on V'. Show that this algorithm returns a Steiner tree whose cost(size) is at most twice the size of the minimum Steiner tree.
