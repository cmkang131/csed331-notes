연결된 무방향 그래프 ( 개 정점, 개 간선) 에서 를 계속 연결 상태로 두면서 제거할 수 있는 간선이 있다면 하나 찾는 알고리즘을 설계하라.

힌트 보기

제거해도 연결이 유지되는 간선은 cycle 위의 간선이다. DFS tree 에 속하지 않는 간선이 그런 간선이다.

정답 보기
  1. 에서 DFS 로 spanning tree ( 개 간선) 를 만든다.
  2. 에 속하지 않는 간선 가 있으면 () 를 제거해도 가 남아 있으므로 는 연결 상태. 그 간선을 답으로 낸다.
  3. 그런 간선이 없으면 이고 는 tree 이다. tree 의 모든 간선은 제거하면 연결이 끊긴다 (bridge) 이므로 답은 "없음".
  4. 시간 DFS 한 번 .
