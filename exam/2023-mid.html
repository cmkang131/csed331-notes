Q1
Describe a linear-time deterministic algorithm for the following task: Given a set L of n
integers and an index k, find the kth smallest element in L. Here, L is not necessarily
sorted. (You don’t need to analyze the correctness of your algorithm, but you have to
analyze the running time of your algorithm.) Design a linear-time algorithm for checking
if it contains a cycle or not. Then prove the correctness of your algorithm.
• + 5 pts: the description of an algorithm for computing an approximate median is
given
• + 5 pts: the description of the overall divide-and-conquer algorithm is given using
the median algorithm as a subroutine
• + 10 pts: time complexity analysis
• No point is given if the running time of your algorithm is superlinear.
주석: 원문에 다른 문제의 문장이 그대로 붙어 있다('Design a linear-time algorithm for checking if it contains a cycle or not. ...'). 인쇄 원문 그대로 [sic].
한국어 풀이 보기

문항 해석. 원문 중 “Design a linear-time algorithm for checking if it contains a cycle...”은 정수 리스트에 사이클을 묻는 문맥상 맞지 않고, 바로 다음 Q2의 문장이 섞인 것으로 보인다. 원문은 [sic] 상태로 보존하고, 이 풀이에서는 루브릭이 지정한 선택(selection) 문제를 푼다.

알고리즘: median of medians. k는 1부터 시작하는 순위라고 한다.

SELECT(L, k):
    if length(L) is small:
        sort L and return its k-th element
    partition L into groups of 5 (last group may be smaller)
    M = median of each group, sorting each group of at most 5
    p = SELECT(M, ceil(length(M) / 2))
    partition L into L_less = elements < p, L_equal = elements = p,
                         and L_greater = elements > p
    if k <= length(L_less):
        return SELECT(L_less, k)
    if k <= length(L_less) + length(L_equal):
        return p
    return SELECT(L_greater, k - length(L_less) - length(L_equal))

위 의사코드의 L<, L=, L>는 각각 피벗보다 작은 값, 같은 값, 큰 값의 부분 배열을 뜻한다. 작은 고정 크기 입력은 직접 정렬한다.

정당성. 그룹 중앙값들의 중앙값 p를 쓰면, 마지막 불완전 그룹과 피벗 그룹의 상수 크기 예외를 제외하고 적어도 약 3n/10개의 원소가 p 이하이고 적어도 약 3n/10개가 p 이상이다. 따라서 피벗과 같지 않은 한쪽으로 재귀할 때 남는 원소 수는 최대 7n/10 + O(1)이다. 분할 뒤 k번째 원소가 어느 부분에 있는지는 각 부분의 크기로 정확히 결정되므로, 해당 부분만 재귀해도 k번째 원소를 잃지 않는다.

시간 분석. 중앙값 배열을 재귀 선택하는 비용과 한 번의 분할 비용을 합치면

T(n) ≤ T(⌈n/5⌉) + T(7n/10 + O(1)) + O(n).

두 재귀 크기의 계수 합은 1/5 + 7/10 = 9/10 < 1이다. 치환법으로 T(m) ≤ am을 가정하면 우변의 선형항 계수는 (9/10)a + c가 된다. a를 충분히 크게 골라 (9/10)a+c < a로 만들고 상수 크기 예외를 흡수하면 T(n)=O(n)이다. 결정적 최악 시간 선형 알고리즘이다.

하한과 공간. 비교 기반 모델에서 이 문제는 k=1인 최소 원소 찾기를 포함한다. 최소 원소를 확정하려면 승자 후보가 아닌 각 원소가 적어도 한 번 비교에서 탈락해야 하므로 최악에 n−1회 비교가 필요하다. 따라서 전체 선택 문제의 최악 시간은 Ω(n)이고, 위 알고리즘은 이 모델에서 Θ(n)이다. 그룹 중앙값과 분할 배열을 별도로 저장하는 단순 구현의 보조 공간은 O(n)이다.

Q2
Design an algorithm for checking if a directed graph has a cycle.
• + 10 pts: the description of a correct algorithm is given. (Return true iff DFS yields
a back edge.)
• + 10 pts: A proof of the fact that there is a back edge iff a graph has a cycle is
given. (If you prove if part only, you get 10 points, but if you prove only-if part
only, you get 5.)
• - 5 pts: small mistakes. A typical mistake: you cannot assume that the root node
of the DFS tree (or the starting vertex of DFS) is one of the vertices in a cycle.
• A typical incorrect answer: during a DFS search, return true when it visits the same
vertex twice. This is not correct as the input graph is a directed graph. In this case,
you get zero.
한국어 풀이 보기

알고리즘. 모든 DFS 트리를 탐색하고, 정점을 미방문(white)·현재 스택(gray)·완료(black)로 표시한다. 현재 간선이 gray 정점을 가리키면 사이클을 발견한 것이다.

HAS-DIRECTED-CYCLE(G):
    color[v] = WHITE for every v
    for each vertex s:
        if color[s] == WHITE and DFS(s):
            return true
    return false

DFS(u):
    color[u] = GRAY
    for each edge (u, v):
        if color[v] == GRAY:
            return true
        if color[v] == WHITE and DFS(v):
            return true
    color[u] = BLACK
    return false

정당성 — “back edge가 있으면 사이클” (if). back edge (u,v)가 발견될 때 v는 현재 DFS 트리에서 u의 조상이다. 트리 경로 v ⇝ u와 간선 (u,v)를 합치면 방향 사이클이다.

정당성 — “사이클이 있으면 back edge” (only if). 유향 사이클이 있다고 하고, 그 사이클에서 가장 먼저 발견된 정점을 v라 하자. DFS는 v의 탐색을 끝내기 전에 사이클의 다음 정점들을 따라가므로 나머지 사이클 정점은 v의 후손으로 발견된다. 사이클의 마지막 간선 (u,v)를 검사할 때 v는 아직 재귀 스택에 있으므로 back edge가 발견된다. DFS 시작 정점 자체가 사이클 위에 있다고 가정할 필요는 없다.

따라서 유향 그래프에 사이클이 존재할 필요충분조건은 DFS에서 back edge를 발견하는 것이다. 이미 방문한 정점을 다시 만났다는 사실만으로 판단하면 안 된다. 검정색 정점으로 가는 forward/cross edge는 사이클을 뜻하지 않을 수 있다.

시간·공간. O(|V|+|E|) 시간, 색상 배열과 재귀 스택을 포함해 O(|V|) 보조 공간이다.

Q3
Let G = (V, E) be an undirected graph with edge weight w : E → R+ . For any two
vertices x, y of G, its widest path is defined as a path π between x and y that maximizes
the weight of the minimum-weight edge in π. Given two vertices x and y of G, design
an efficient algorithm for computing a widest path between x and y in G. Then state
the running time of your algorithm. (You don’t need to prove the correctness of your
algorithm.)
• + 20 pts: O(|E| log |E|)-time algorithm. You can achieve this by modifying Dijk-
stra’s algorithm. A main difference is that, for an edge u, v, we update dist(u)=
max{ dist(u), min{ dist(v), wuv }}. Also, we use a max heap instead of a min heap.
If your update procedure is not correct, you get +10 (out of 20). An alternative
algorithm is as follows. Compute a maximum spanning tree using a modification of
Kruskal’s algorithm, and then return an arbitrary path in the maximum spanning
tree.
• + 10 pts: O(|E| · |V |) or O(|E|2 )-time algorithm
• +5 pts: exponential-time algorithm.
• 0 pts: if your algorithm is not correct.
한국어 풀이 보기

정의. 경로 π의 폭(bottleneck)은 그 경로에 속한 간선 가중치의 최솟값이다. best[v]를 x에서 v로 가는 경로 폭의 최댓값으로 구한다.

WIDEST-PATH(G, x, y):
    best[v] = -infinity and parent[v] = NIL for every v
    best[x] = +infinity
    initialize a max-priority queue keyed by best[·]
    while the queue is not empty:
        v = extract-max()
        if v == y: break
        for each edge (v, u) with weight w(v,u):
            candidate = min(best[v], w(v,u))
            if candidate > best[u]:
                best[u] = candidate
                parent[u] = v
                increase/update u's queue key
    if best[y] == -infinity: return “no path”
    reconstruct x-to-y path by following parent pointers from y

정당성 요지. 경로에 간선 (v,u)를 붙였을 때 폭은 min(best[v], w(v,u))가 된다. 따라서 완화식 best[u] ← max(best[u], min(best[v], w(v,u)))는 가능한 경로의 폭을 정확히 비교한다. 최대 우선순위 큐에서 현재 폭이 가장 큰 정점을 확정하는 것은 Dijkstra 알고리즘의 탐욕 논증과 같은 방식으로 정당화된다. 부모 포인터는 해당 최적 폭을 만드는 경로를 복원한다.

시간·공간. 이진 힙으로 각 정점의 키를 갱신하고 각 간선을 상수 번 검사하면 일반적으로 O((|V|+|E|) log |V|) 시간, 입력 그래프 외에 O(|V|) 보조 공간이다. x와 y가 같은 연결 성분에 있고 간선이 있는 연결 그래프라면 |V|=O(|E|)이므로 루브릭의 O(|E| log |E|)로 쓸 수 있다. 서로 연결되지 않았다면 경로가 없다고 반환한다.

동등한 대안. 최대 스패닝 트리를 Kruskal 방식으로 만든 뒤 그 트리에서 x와 y를 잇는 유일 경로를 반환해도 된다. 최대 스패닝 트리 경로의 최소 간선은 다른 어떤 x-y 경로의 최소 간선보다 작을 수 없다. 연결 그래프에서 정렬 비용을 포함한 시간은 O(|E| log |E|)이다.

Q4
Prove that if G has a cycle with a unique heaviest edge e, then e cannot be part of any
MST.
• -10 points: in the case that you do not specify e′ ; you should give a clear definition
of e′ . If you choose e′ arbitrary, T ′ = T + e′ − e is not necessarily a tree.
한국어 풀이 보기

증명. 사이클 C의 유일한 최중량 간선이 e=uv라고 하자. 어떤 MST T가 e를 포함한다고 가정한다.

  1. T에서 e를 제거하면 두 연결 성분 A, B로 나뉘며 u와 v는 서로 다른 성분에 속한다.
  2. 사이클에서 e를 뺀 나머지 간선들은 u에서 v로 가는 경로를 이룬다. 이 경로는 A에서 B로 적어도 한 번 건너야 한다. 그 컷을 가로지르는 C \ {e}의 간선 하나를 e′로 명시해 선택한다.
  3. e가 C의 유일한 최중량 간선이므로 w(e′) < w(e)다. e′는 두 성분을 연결하므로 T′ = (T − {e}) ∪ {e′}는 스패닝 트리이며 T보다 가볍다.

이는 T가 MST라는 가정에 모순이다. 따라서 e는 어떤 MST에도 포함될 수 없다. 임의의 간선 e′를 택하면 트리가 된다는 보장이 없으므로, 위처럼 T−e의 두 성분을 가로지르는 사이클 간선으로 정의해야 한다.

시간·공간. 증명 문제이므로 알고리즘 복잡도 분석은 해당하지 않는다.

Q5
Mark True or False for the following statements. No justification is needed.
(1) In the union-find data structure with path compression, every tree representing a
connected component always have depth at most O(log∗ n).
(2) In the union-find data structure with path compression, a single find operation takes
O(log n) time.
(3) The Huffman tree is a balanced binary tree.
(4) Huffman encoding guarantees that a symbol with smallest frequency always gets a
shortest code-word.
(5) Let L0 , L1 , . . . be the layers of the vertices of G constructed by the breadth-first
search algorithm. Let (x, y) be an edge of G such that x ∈ Li and y ∈ Lj with two
indices i and j. Then |i − j| ≤ 1.
(6) A directed graph admits a topological ordering only when it is acyclic.
• Correct answer: FTFFTT
• +3 points for each subproblem, and additional 2 points are given if all answers are
correct.
한국어 풀이 보기

원문 루브릭 보존. 문제 블록에 인쇄된 정답은 FTFFTT이며, 원문과 이 표기는 수정하지 않았다. 다만 독립적인 수학 검증에서는 (2)의 조건 누락을 분리해서 봐야 한다.

  1. (1) F. path compression만으로는 모든 시점의 트리 깊이가 O(log* n)로 제한되지 않는다. 압축되지 않은 긴 사슬이 존재할 수 있다.
  2. (2) 조건부. path compression만 사용하면 아직 압축되지 않은 깊이 n−1 사슬에서 단일 find가 Θ(n) 시간이 걸릴 수 있으므로, 원문에 적힌 조건만으로는 “single find is O(log n)”가 보장되지 않는다. 반면 union-by-rank/size를 함께 사용하면 트리 높이가 O(log n)이어서 단일 find도 O(log n)이다. 즉 인쇄 키의 T는 이 추가 가정을 전제로 해야 한다.
  3. (3) F. Huffman 트리는 일반적으로 균형 이진 트리가 아니다. 빈도 분포에 따라 깊이가 크게 다른 잎을 가질 수 있다.
  4. (4) F. Huffman 코드는 최소 빈도 기호에 항상 최단 코드워드를 보장하지 않는다. 예를 들어 빈도가 a=1,b=1,c=2,d=4이면 Huffman 병합 후 a,b는 깊이 3, c는 깊이 2, d는 깊이 1인 트리를 만들 수 있다. 가장 낮은 빈도인 a,b가 최단 코드워드를 받지 않는다.
  5. (5) 조건부 T. G가 무방향 그래프이면 간선 양끝의 BFS 거리 차이는 최대 1이다. 양방향으로 d(y) ≤ d(x)+1, d(x) ≤ d(y)+1이기 때문이다. 원문에 무방향 조건이 없다면 유향 그래프에서는 이 절댓값 조건이 일반적으로 거짓이다. 인쇄 키 T는 무방향 그래프를 전제로 한 것으로 해석해야 한다.
  6. (6) T. 위상 순서가 있다면 모든 간선이 앞선 정점에서 뒤선 정점으로 향하므로 방향 사이클은 불가능하다. 실제로 유향 그래프가 위상 순서를 갖는 것과 DAG인 것은 동치다.

경우별 결과. 인쇄된 루브릭 문자열 FTFFTT는 그대로 보존한다. (i) G가 무방향이고 path compression만 명시된 문언대로라면 (2)는 F이므로 FFFFTT다. (ii) G가 유향 그래프일 수도 있다고 엄격히 읽으면 (5)도 보장되지 않아 FFFFFT다. (iii) 인쇄 키 FTFFTT는 union-by-rank/size와 path compression을 함께 사용하고 G가 무방향이라는 두 조건을 추가해야 일관된다.

시간·공간. 참·거짓 판별 문제이므로 알고리즘 복잡도 분석은 해당하지 않는다.
