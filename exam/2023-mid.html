Q1
Describe a linear-time deterministic algorithm for the following task: Given a set L of n integers and an index k, find the kth smallest element in L. Here, L is not necessarily sorted. (You don’t need to analyze the correctness of your algorithm, but you have to analyze the running time of your algorithm.) Design a linear-time algorithm for checking if it contains a cycle or not. Then prove the correctness of your algorithm. • + 5 pts: the description of an algorithm for computing an approximate median is given • + 5 pts: the description of the overall divide-and-conquer algorithm is given using the median algorithm as a subroutine • + 10 pts: time complexity analysis • No point is given if the running time of your algorithm is superlinear.

Q2
Design an algorithm for checking if a directed graph has a cycle. • + 10 pts: the description of a correct algorithm is given. (Return true iff DFS yields a back edge.) • + 10 pts: A proof of the fact that there is a back edge iff a graph has a cycle is given. (If you prove if part only, you get 10 points, but if you prove only-if part only, you get 5.) • - 5 pts: small mistakes. A typical mistake: you cannot assume that the root node of the DFS tree (or the starting vertex of DFS) is one of the vertices in a cycle. • A typical incorrect answer: during a DFS search, return true when it visits the same vertex twice. This is not correct as the input graph is a directed graph. In this case, you get zero.
Q3
Let G = (V, E) be an undirected graph with edge weight w : E → R+ . For any two vertices x, y of G, its widest path is defined as a path π between x and y that maximizes the weight of the minimum-weight edge in π. Given two vertices x and y of G, design an efficient algorithm for computing a widest path between x and y in G. Then state the running time of your algorithm. (You don’t need to prove the correctness of your algorithm.) • + 20 pts: O(|E| log |E|)-time algorithm. You can achieve this by modifying Dijk- stra’s algorithm. A main difference is that, for an edge u, v, we update dist(u)= max{ dist(u), min{ dist(v), wuv }}. Also, we use a max heap instead of a min heap. If your update procedure is not correct, you get +10 (out of 20). An alternative algorithm is as follows. Compute a maximum spanning tree using a modification of Kruskal’s algorithm, and then return an arbitrary path in the maximum spanning tree. • + 10 pts: O(|E| · |V |) or O(|E|2 )-time algorithm • +5 pts: exponential-time algorithm. • 0 pts: if your algorithm is not correct.
