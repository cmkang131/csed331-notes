가중치 인 무방향 그래프에서 두 정점 의 widest path 는 경로 위 최소 가중치 간선의 가중치를 최대화하는 - 경로이다. 이를 구하는 효율적 알고리즘과 running time 을 제시하라. (정당성 증명은 불필요)

힌트 보기

Dijkstra 를 변형한다: 합 대신 경로의 최소값, min heap 대신 max heap.

정답 보기
  1. width[x] = +inf; width[v] = 0 for v != x
MaxHeap H = {x}
while H not empty:
  u = H.extractMax()
  if u == y: break
  for each edge (u, v, w):
    cand = min(width[u], w)
    if cand > width[v]:
      width[v] = cand; parent[v] = u; H.insert/increase(v)
return path via parent from y
  2. 시간 간선마다 heap 갱신 한 번: (Dijkstra 와 동일).
  3. 이유 경로를 늘릴수록 병목은 줄기만 하므로 (단조), 가장 큰 width 를 가진 정점은 더 좋아질 수 없다. Dijkstra 의 greedy 논증이 그대로 적용된다.
  4. 다른 풀이 가중치 최대 spanning tree 를 만든 뒤 - 경로를 쓴다 (Kruskal 을 내림차순으로). 나이브하게 모든 경로를 보면 지수 시간.
