Q1

(20pts) Suppose someone presents you with a solution to a max-flow problem on some network. Give a linear time algorithm to determine whether the solution does indeed give a maximum flow.

Q2

(10pts) Euclidean TSP is the following problem: given a set of n points in the plane, find a shortest tour that starts at a point, visits every point exactly once, and returns to the starting point, where the pairwise distance of the points is their Euclidean distance. Give an efficient 2-approximation algorithm for Euclidean TSP problem, and show that it always returns a 2-approximation tour.

Q3

(20pts) A vertex cover of an undirected graph is a subset of the vertices which touches every edge. Let G = (V, E) is a bipartite graph. Show that the problem of finding the minimum vertex cover in G reduces to the maximum-flow problem, and thereby to linear programming. (Hint: Relate the minimum vertex cover problem to the minimum cut in an appropriate network.)

Q4

(10pts) Let G = (V, E) be an undirected graph with n nodes. Show that a set of nodes S is a vertex cover of G if and only if the remaining nodes, V ∖ S, are an independent set of G.
