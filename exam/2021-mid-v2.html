Q1
(20 points) Let f, g and h be real-valued functions defined on N. Prove or disprove the following.
(a) If f (n) = Ω(g(n)), then 2f (n) = Ω(2g(n) ).
(b) If f (n) = O(g(n)) and g(n) = O(h(n)), then f (n) = O(h(n)).
한국어 풀이 보기

정의(실수값 함수). 이 풀이에서는 부호가 임의일 수 있는 실수값 함수에 대해 f = O(g)를 “어떤 c > 0, n₀가 있어 모든 n ≥ n₀에서 |f(n)| ≤ c|g(n)|”로 정의한다. Ω도 절댓값을 사용한 하한으로 해석한다.

(a) 지수 표기라면 거짓. HTML 전사본에는 식이 2f(n), 2g(n)처럼 표시되어 지수 여부가 불분명하다. 초안이 의도한 식 2f(n) = Ω(2g(n))로 해석하면 다음 반례가 있다. g(n)=log₂ n, f(n)=½ log₂ n이면 |f(n)| = ½|g(n)|이므로 f = Ω(g)다. 하지만 2f(n)=√n, 2g(n)=n이고 √n은 Ω(n)이 아니다. 비율 √n/n = 1/√n은 0으로 수렴한다.

표기를 문자 그대로 곱셈으로 읽으면 (a)는 참이다. 2f(n)와 2g(n)가 각각 상수 2를 곱한 함수라면, |f(n)| ≥ c|g(n)|에서 |2f(n)| ≥ c|2g(n)|가 바로 따른다. 원문 블록은 보존했으므로, 채점 전 원본 스캔에서 지수 표기를 확인해야 한다.

(b) 참: O의 추이성. f = O(g)와 g = O(h)이므로 충분히 큰 모든 n에서 |f(n)| ≤ c₁|g(n)|, |g(n)| ≤ c₂|h(n)|를 만족하는 상수 c₁,c₂ > 0가 있다. 두 부등식을 결합하면 |f(n)| ≤ c₁c₂|h(n)|이므로 f = O(h)다. 시작점은 max(n₁,n₂)로 잡으면 된다.

시간·공간. 함수의 점근 관계를 증명하는 문제이므로 알고리즘 복잡도 분석은 해당하지 않는다.

Q2
(30 points) Design an efficient algorithm for the following problem using a divide-and-conquer approach.
Given a list L of n integers, compute the number of pairs (i, j) of indices satisfying that L[i] < L[j].
Then analyze the running time of your algorithm.
주석: 인쇄 원문에는 i<j 조건이 없다. 문자 그대로 읽으면 L[i]<L[j]인 순서쌍 수라 정렬로 자명해진다. 기존 풀이의 inversion 해석(i<j 가정)과 다르므로 원문을 유지하고 모호성만 표시한다.
한국어 풀이 보기

원문 그대로의 해석. 원문에는 i < j가 없다. 따라서 모든 순서쌍 (i,j) 중 L[i] < L[j]를 만족하는 수를 센다. 같은 값끼리는 세지 않는다.

COUNT-ALL-PAIRS(L):
    B = mergeSort(copy(L))
    ans = 0
    for each x in L:
        p = upper_bound(B, x)   // 처음으로 x보다 큰 원소의 위치
        ans = ans + (n - p)
    return ans

upper_bound는 정렬 배열에서 x보다 큰 첫 원소의 위치를 반환한다(0부터 시작하는 인덱스). 그 뒤의 n-p개가 정확히 x보다 큰 원소이므로 각 첫 번째 인덱스 i에 대한 가능한 j를 빠짐없이 센다. 시간은 정렬과 이진 탐색을 합쳐 O(n log n), 보조 공간은 O(n)이다.

의도한 문제가 i < j인 증가 쌍을 세는 것이라면 별도 문제다. 이 경우 왼쪽 절반의 인덱스는 오른쪽 절반의 인덱스보다 항상 앞선다는 점을 이용해 병합정렬로 센다.

COUNT-INCREASING(L):
    if length(L) <= 1: return (0, L)
    (cL, A) = COUNT-INCREASING(left half of L)
    (cR, B) = COUNT-INCREASING(right half of L)
    j = 0; cross = 0
    for x in A in ascending order:
        while j < length(B) and B[j] <= x:
            j = j + 1
        cross = cross + (length(B) - j)
    return (cL + cR + cross, merge(A, B))

A, B는 원래 인덱스의 왼쪽/오른쪽 절반에서 정렬된 값들이다. 각 x에 대해 오른쪽에서 x보다 큰 값만 세며, 포인터 j는 단조롭게 움직이므로 교차 쌍을 선형 시간에 센다. 등호를 먼저 건너뛰어 중복값을 잘못 세지 않는다. 점화식은 T(n)=2T(n/2)+O(n)이므로 시간 O(n log n), 보조 공간 O(n)이다.

초안 교정. 초안의 inversion 계산은 i < j이면서 L[i] > L[j]인 역전 쌍을 센다. 이는 의도된 증가 쌍 L[i] < L[j]과 부등호가 반대이므로 그대로 사용하면 오답이다.

Q3
(20 points) Given a directed graph G = (V, E), design a linear-time algorithm for checking if it has a
cycle. You do not need to prove the correctness/time complexity of the algorithm.
한국어 풀이 보기

알고리즘: 색상 DFS. 흰색은 미방문, 회색은 현재 재귀 스택에 있는 정점, 검정색은 탐색 완료 정점을 뜻한다.

HAS-DIRECTED-CYCLE(G):
    color[v] = WHITE for every v
    for each vertex u:
        if color[u] == WHITE and DFS(u):
            return true
    return false

DFS(u):
    color[u] = GRAY
    for each edge (u, v):
        if color[v] == GRAY:
            return true       // back edge
        if color[v] == WHITE and DFS(v):
            return true
    color[u] = BLACK
    return false

방향 그래프에서 현재 스택의 조상으로 향하는 back edge가 있으면 그 조상에서 현재 정점까지의 DFS 트리 경로와 해당 간선이 사이클을 이룬다. 반대로 유향 사이클이 있으면 그 사이클에서 가장 먼저 발견된 정점이 탐색 중인 동안 사이클의 나머지 정점들이 그 후손으로 발견되고, 마지막 간선은 그 정점으로 돌아가는 back edge가 된다.

시간·공간. 각 정점은 한 번씩 색이 바뀌고 각 간선은 상수 번 검사되므로 O(|V|+|E|) 시간, 색상 배열과 재귀 스택을 포함해 O(|V|) 보조 공간이다.

Q4
(30 points) Prove or disprove the following. Let G = (V, E) be an edge-weighted undirected graph.
(a) Assume that G has a cycle C such that the weights of the edges of C are all distinct. Then the
lightest edge of C is contained in every minimum spanning tree of G.
(b) If the lightest edge in G is unique, then it must be contained in every minimum spanning tree of
G.
한국어 풀이 보기

(a) 거짓. 정점 A,B,C,D와 다음 간선을 둔다.

  • 삼각형: AB=5, BC=6, CA=7
  • 별 모양 간선: DA=1, DB=2, DC=3

삼각형은 가중치가 모두 다르고 가장 가벼운 간선은 AB=5다. 하지만 트리 {DA, DB, DC}는 모든 정점을 연결하고 총 가중치가 1+2+3=6이다. 각 정점 A, B, C의 단일 정점 컷에서 각각 DA, DB, DC가 유일한 최소 간선이다. 이 성질은 교환 논증으로 확인된다. 어떤 스패닝 트리가 해당 최소 간선 e를 빠뜨리면 e를 더해 생긴 사이클에서 같은 컷을 가로지르는 더 무거운 간선 f를 제거해 트리 가중치를 낮출 수 있다. 따라서 세 별 간선은 모든 MST에 들어가며, 이들이 이미 트리를 이루므로 별 모양 트리가 유일한 MST다. AB는 포함되지 않는다.

(b) 참. 그래프 전체에서 유일하게 가장 가벼운 간선을 e=uv라 하자. 어떤 MST T가 e를 포함하지 않는다고 가정하면, T+e에 사이클이 생긴다. 그 사이클에서 u에 인접한 기존 트리 간선 하나를 f라 하자. e가 그래프 전체의 유일한 최소 간선이므로 w(f)>w(e)다. T+e-f는 더 가벼운 스패닝 트리여서 모순이다. 따라서 e는 모든 MST에 포함된다.

시간·공간. 증명 문제이므로 알고리즘 복잡도 분석은 해당하지 않는다.
