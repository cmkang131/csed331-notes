· 같은 학기 중간고사가 두 버전으로 전해진다. version 1과 문제가 다르므로 둘 다 보존한다.

Q1
(20 points) Let f, g and h be real-valued functions defined on N. Prove or disprove the following. (a) If f (n) = Ω(g(n)), then 2f (n) = Ω(2g(n) ). (b) If f (n) = O(g(n)) and g(n) = O(h(n)), then f (n) = O(h(n)).
Q2
(30 points) Design an efficient algorithm for the following problem using a divide-and-conquer approach. Given a list L of n integers, compute the number of pairs (i, j) of indices satisfying that L[i] < L[j]. Then analyze the running time of your algorithm.
주석: 인쇄 원문에는 i<j 조건이 없다. 문자 그대로 읽으면 L[i]<L[j]인 순서쌍 수라 정렬로 자명해진다. 기존 풀이의 inversion 해석(i<j 가정)과 다르므로 원문을 유지하고 모호성만 표시한다.
Q3
(20 points) Given a directed graph G = (V, E), design a linear-time algorithm for checking if it has a cycle. You do not need to prove the correctness/time complexity of the algorithm.
Q4
(30 points) Prove or disprove the following. Let G = (V, E) be an edge-weighted undirected graph. (a) Assume that G has a cycle C such that the weights of the edges of C are all distinct. Then the lightest edge of C is contained in every minimum spanning tree of G. (b) If the lightest edge in G is unique, then it must be contained in every minimum spanning tree of G.
