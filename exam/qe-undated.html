Q1
(20pts) Give a sorting algorithm whose average time complexity is O(n log n), where n is the number
of input values. Show that the average time complexity is O(n log n) for that algorithm.
한국어 풀이 (접기/펼치기)

알고리즘. 무작위 피벗을 사용하는 Quicksort를 쓴다. 각 단계에서 피벗을 무작위로 고르고, 한 번의 partition으로 피벗보다 작은 값과 큰 값을 나눈 뒤 양쪽을 재귀 정렬한다. 중복 키가 있다면 원래 위치를 보조 키로 사용해 순위를 구별할 수 있다.

기댓값 분석. 키가 서로 다른 순서 통계량을 z₁<…<zₙ이라 하자. i<j인 두 키가 비교되는 사건을 Xij라 둔다. zᵢ와 zⱼ가 비교되려면 구간 {zᵢ,…,zⱼ}에서 최초로 피벗이 되는 키가 양 끝 zᵢ 또는 zⱼ여야 한다. 이 구간의 각 키가 최초 피벗일 확률은 같으므로

E[Xij] = 2/(j−i+1).

전체 비교 횟수 C는 모든 쌍의 비교 지표변수 합이므로 선형성에 의해

E[C] = Σi<j 2/(j−i+1)
= 2 Σd=1n−1 (n−d)/(d+1)
= 2(n+1)Hn − 4n = O(n log n),

여기서 Hn=1+1/2+…+1/n=O(log n)이다. 각 partition의 작업량은 비교 횟수에 선형 비례하므로 기대 실행시간도 O(n log n)이다.

공간. in-place partition을 쓰면 재귀 스택을 제외한 추가 공간은 O(1)이고, 무작위 피벗에 대한 기대 스택 깊이는 O(log n)이다. 최악의 스택 공간은 O(n)이다. 이 분석은 임의의 고정 입력에 대해 피벗 무작위성의 기댓값을 취하므로, 입력 분포를 가정한 평균 분석보다 강하다.

Q2
(20pts) Let G be a weighted undirected graph that contains no cycle. Let n be the number of vertices
in G. The time complexities in (b) and (c) below should be represented in terms of n.
(a) Give an efficient algorithm that computes the longest path length between two given vertices of
G.
(b) If the edges of G are represented using adjacency lists, what is the time complexity of the algorithm
you have proposed in (a)?
(c) If the edges of G are represented using an adjacency matrix, what is the time complexity of the
algorithm you have proposed in (a)?
한국어 풀이 (접기/펼치기)

(a) 알고리즘. 사이클이 없는 무방향 그래프는 포리스트다. 두 정점 s,t가 같은 연결 요소에 있으면 그 사이의 단순 경로는 유일하다. s에서 DFS/BFS를 하며 parent와 누적 가중치 dist를 저장한다. t를 찾으면 dist[t]가 유일한 경로의 길이이자 최장 경로 길이다. 서로 다른 연결 요소에 있으면 경로가 없다고 보고한다. 간선 가중치가 음수여도 경로가 유일하므로 합을 그대로 계산하면 된다.

DFS(s)
parent[s] = NIL; dist[s] = 0
for each visited neighbor v of u:
    if v != parent[u]:
        parent[v] = u
        dist[v] = dist[u] + weight(u,v)
if t is reached: return dist[t]
else: return "no path"

정당성. 사이클이 없으므로 같은 연결 요소의 두 정점 사이 단순 경로는 하나뿐이다. DFS/BFS는 그 경로의 모든 간선을 따라 dist를 누적하므로 반환값은 유일한 경로의 가중치 합이며, 따라서 최장 경로 길이다.

(b) 인접 리스트. 포리스트의 간선 수 m≤n−1이다. 방문 정점과 간선을 상수 번 처리하므로 O(n+m)=O(n) 시간, O(n) 보조 공간이다.

(c) 인접 행렬. 방문한 각 정점에서 이웃을 찾으려면 행의 n개 칸을 검사해야 한다. 최악에 O(n)개 정점을 방문하므로 시간 O(n²), 방문/부모/거리 배열의 보조 공간은 O(n)이다. 행렬 자체의 입력 저장 공간은 O(n²)이다.

Q3
(20pts) Professor Tiger claims that “any edge of minimum weight in an undirected connected graph G
must be part of some MST of G.” Either prove the claim if it is correct, or give a counterexample if
it is not correct.
한국어 풀이 (접기/펼치기)

주장은 참이다. 최소 가중치 간선을 e=(u,v)라 하자. 임의의 최소 스패닝 트리 T가 이미 e를 포함하면 끝이다. 포함하지 않는다고 가정한다.

  1. T에 e를 추가하면 정확히 하나의 사이클이 생긴다.
  2. 그 사이클에서 e 이외에 u에 접하는 간선을 f=(u,w) 하나 고른다. f는 컷 ({u}, V∖{u})를 가로지르는 간선이다.
  3. e가 그래프 전체에서 최소 가중치 간선이므로 w(e)≤w(f)이다.
  4. T′=T+e−f는 사이클을 끊은 스패닝 트리이고 w(T′)=w(T)+w(e)−w(f)≤w(T)이다. T가 이미 최소 스패닝 트리이므로 더 가벼운 트리는 있을 수 없고, 따라서 w(T′)=w(T)다.

결국 T′도 MST이며 e를 포함한다. 가중치 동률이 있어도 부등식과 교환 논증은 그대로 성립한다. 따라서 그래프에서 최소 가중치를 갖는 각 간선은 적어도 하나의 MST에 포함된다.

복잡도. 이는 존재성 증명이며 알고리즘을 요구하지 않는다. 주어진 T에서 e를 추가한 사이클을 찾는 교환 절차는 트리 경로 탐색으로 O(n) 시간에 수행할 수 있다.

Q4
(20pts) Let P be a convex polygon in the plane whose n vertices p1 , p2 , . . . , pn are given (stored in
an array) in clockwise order along its boundary satisfying that p1 is the leftmost vertex, pn is the
rightmost vertex pn , and pi lies above the line segment p1 pn for all 1 < i < n . Given a line `, we
would like to find the vertex of P where a translated copy of ` is tangent to P from above. Design a
O(log n)-time algorithm for finding such a tangent vertex, and analyze the running time.
한국어 풀이 (접기/펼치기)

유한 기울기의 직선. ℓ을 y=mx+b로 쓰자. ℓ을 평행 이동해 다각형을 위에서 지지하는 선이 되게 하면, 접점은

f(pᵢ)=yᵢ−m xᵢ

를 최대화하는 꼭짓점이다. 주어진 순서 p₁,…,pₙ은 왼쪽 끝에서 오른쪽 끝으로 가는 볼록 다각형의 위쪽 사슬이다. 이 사슬의 비수직 변 기울기 sᵢ=(yᵢ₊₁−yᵢ)/(xᵢ₊₁−xᵢ)는 볼록성 때문에 비증가한다. 따라서

f(pᵢ₊₁)−f(pᵢ) = (yᵢ₊₁−yᵢ)−m(xᵢ₊₁−xᵢ)

의 부호는 양수에서 음수로 최대 한 번만 바뀐다. 즉 f(pᵢ)는 단봉(unimodal)이다. 끝점에서 수직 변이 있으면 그 변화량은 각각 위쪽 끝에서 양수, 오른쪽 끝에서 음수로 처리되어 같은 단봉성을 유지한다.

이진 탐색. Δᵢ=f(pᵢ₊₁)−f(pᵢ)를 O(1)에 계산한다. Δᵢ≤0인 첫 위치를 이진 탐색으로 찾으면 해당 pᵢ가 최대점이다. 그런 위치가 없으면 pₙ이 최대점이다. Δᵢ=0인 평탄 구간에서는 그 구간의 어느 꼭짓점이나 접점이므로 첫 비양수 위치를 반환해도 된다.

lo = 1; hi = n-1
while lo <= hi:
    mid = floor((lo+hi)/2)
    if f(p[mid+1]) - f(p[mid]) <= 0:
        hi = mid-1
    else:
        lo = mid+1
if lo == n: return p[n]
else: return p[lo]

각 단계는 상수 시간이고 탐색 구간이 절반으로 줄어들므로 시간 O(log n), 추가 공간 O(1)이다.

수직선 경계의 원문 모호성. 수직선 x=c에는 y=mx+b 형태의 유한 기울기가 없고, “위에서” 평행 이동한다는 표현만으로는 왼쪽 지지선과 오른쪽 지지선 중 어느 쪽을 뜻하는지 결정되지 않는다. 수직선을 법선 방향으로 지지선으로 해석한다면 부호 선택을 별도 규정해야 한다. 오른쪽 지지선을 택하면 오른쪽 끝 pₙ, 왼쪽 지지선을 택하면 왼쪽 끝 p₁(동률 꼭짓점이 있을 수 있음)이다. 따라서 원문 그대로는 수직선의 답이 유일하게 정해지지 않는다.

Q5
(20pts) Let G = (V, E) be an undirected graph. In the Independent Set problem we are given an
integer g, and the aim is to find a set D ⊆ V of g vertices such that no two vertices of D have an
edge between them. In the Vertex Cover problem, we are given an integer b, and the aim is to find
a C ⊆ V of b vertices such that every edge of E is incident to at least one vertex of C. Show that
Vertex Cover is NP-complete, assuming that Independent Set is NP-complete.
한국어 풀이 (접기/펼치기)

보조정리. 그래프 G에서 C가 vertex cover일 필요충분조건은 V∖C가 independent set인 것이다. C가 간선의 모든 끝점을 덮으면 V∖C 안에 양 끝점이 모두 들어가는 간선은 없으므로 독립집합이다. 반대로 V∖C가 독립집합이면 모든 간선의 적어도 한 끝점은 C에 있어야 한다.

감소. Independent Set의 입력 (G,g), n=|V|를 Vertex Cover의 입력 (G,b)로 보내되 b=n−g로 둔다. 보조정리에 의해

G에 크기 g의 독립집합 존재
⟺ G에 크기 n−g의 정점 커버 존재.

변환은 O(1) 추가 계산으로 수행된다. 문제의 “정확히 g개/ b개” 해석에서도, 크기가 더 큰 독립집합은 g개를 택해 줄일 수 있고, 크기가 더 작은 정점 커버는 b≤n일 때 임의의 정점을 추가해 정확히 b개로 늘릴 수 있으므로 표준적인 “적어도 g개/최대 b개” 형태와 결정 가능성이 같다.

NP 소속. 후보 C를 받으면 크기가 b인지 확인하고 각 간선의 적어도 한 끝점이 C에 있는지 검사하면 된다. 인접 리스트에서 O(n+m) 시간이다. Independent Set이 NP-complete라는 가정 아래 위 다항 시간 감소는 Vertex Cover의 NP-hardness를 보이고, NP 소속과 합쳐 NP-complete임을 얻는다.
