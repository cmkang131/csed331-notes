N! = 1 · 2 · 3 … N 을 계산하는 문제를 생각하자.

(a) N 이 n 비트 수일 때, N!은 대략 몇 비트인가 (Θ 표기로 답하라).

(b) N!을 계산하는 알고리즘을 제시하고 수행 시간을 분석하라. 단, 두 n 비트 수의 곱셈에 O(log n) 시간이 걸린다고 가정한다. [원문: 곱셈 비용이 인쇄 원문에서 O(log n)으로 되어 있음 — 그대로 옮김. 실제 알려진 곱셈 알고리즘(초등법 O(n2), FFT 계열 O(n log n))과는 다른 가정이므로 오쇄 가능성이 있다. 아래 풀이는 이 가정을 문면 그대로 적용한 것이다.]

힌트 보기

(a) N!의 비트 수는 log2(N!) = Σk=1..N log2 k. Stirling 근사(log N! = N log N − N log e + O(log N))을 쓴다. n 비트 수라는 것은 N = Θ(2n)이라는 뜻이다. (b) 곱셈 횟수는 N−1번. 중간 결과의 비트 길이는 (a)의 결과를 넘지 않는다.

정답 보기
  1. (a) 비트 수 = log2(N!) + O(1) = Θ(N log N). N = Θ(2n)이므로 log N = Θ(n)이고, 답은 Θ(n · 2n) 비트 (= Θ(N log N)).
  2. (b) 알고리즘 r ← 1; for k = 2, 3, …, N: r ← r · k.
  3. 곱셈 횟수 N−1 = Θ(2n) 번. k 번째 곱셈에서 r = (k−1)!의 비트 길이는 (a)에 의해 최대 Θ(n · 2n) 비트이다.
  4. 시간 문제의 가정을 피연산자 비트 길이 m 에 대해 O(log m)으로 적용하면, 매 곱셈은 O(log(n · 2n)) = O(n). 따라서 총 O(n · 2n). (원문의 n을 입력 크기로 고정해 해석하면 곱셈 Θ(2n)회 × O(log n) = O(2n log n)이 되지만, 이는 곱셈 비용이 피연산자 길이와 무관하게 입력의 n에만 의존한다는 추가 가정이 필요한 해석이다.)
