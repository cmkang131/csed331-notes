Q1
(10 points) Given two strings x = x1 x2 . . . xn and y = y1 y2 . . . ym , we wish to find the
length of their longest common substring, that is, the largest k for which there are indices
i and j with xi xi+1 . . . xi+k−1 = yj yj+1 . . . yj+k−1 . Design an O(mn)-time algorithm for
this problem, and provide a complete pseudocode of your algorithm. You don’t need to
analyze your algorithm.
한국어 풀이 (독립 검증)

정의. L[i][j]를 x[i..n]와 y[j..m]가 공유하는 공통 접두사의 최대 길이로 둔다. 이는 공통 부분문자열(substring)의 시작 위치가 각각 i,j인 경우의 최장 길이다.

L[1..n+1][1..m+1] ← 0
best ← 0
for i ← n downto 1:
    for j ← m downto 1:
        if x[i] = y[j]:
            L[i][j] ← 1 + L[i+1][j+1]
            best ← max(best, L[i][j])
        else:
            L[i][j] ← 0
return best

정당성. 두 접미사의 첫 문자가 다르면 그 위치에서 시작하는 공통 부분문자열의 길이는 0이다. 같으면 두 첫 문자를 포함하고, 나머지 길이는 바로 뒤 접미사 쌍의 최장 공통 접두사 길이이므로 점화식은 정확하다. 인덱스를 감소시키며 계산하므로 L[i+1][j+1]은 이미 계산되어 있다. 모든 가능한 시작 위치 쌍을 검사해 최댓값을 취하므로 전체 최장 공통 부분문자열 길이를 반환한다.

복잡도. 각 (i,j)를 상수 시간에 한 번 처리하므로 시간 O(nm), 표 공간 O(nm).

Q2
(10 points) Given integers n and k, along with p1 , . . . , pn ∈ [0, 1], you want to determine
the probability of obtaining exactly k heads when n biased coins are tossed independently
at random, where pi is the probability that the ith coin comes up heads. Give an O(n2 )-
time algorithm for this task. Assume you can multiply and add two numbers in [0, 1] in
O(1) time. Give a complete pseudocode of your algorithm. You don’t need to analyze
the running time of your algorithm.
한국어 풀이 (독립 검증)

DP 정의. P[i][j]를 처음 i개 동전에서 정확히 j개의 앞면이 나올 확률로 둔다. 범위 밖의 값은 0으로 취급한다.

if k < 0 or k > n: return 0
P[0..n][0..n] ← 0
P[0][0] ← 1
for i ← 1 to n:
    for j ← 0 to i:
        tail ← P[i-1][j]
        head ← 0
        if j > 0: head ← P[i-1][j-1]
        P[i][j] ← (1-p[i])·tail + p[i]·head
return P[n][k]

정당성. 처음 i개 동전에서 앞면이 정확히 j개인 경우는 서로 배타적인 두 경우다. i번째 동전이 뒷면일 확률은 1-p[i]이고 앞의 i-1개에서 j개가 앞면이어야 한다. i번째 동전이 앞면일 확률은 p[i]이고 앞의 동전에서 j-1개가 앞면이어야 한다. 독립성으로 두 항을 더하면 점화식이 된다. 기저 P[0][0]=1도 맞으므로 귀납적으로 모든 표 항이 정확하다.

복잡도. 표의 칸 수는 O(n²)이고 칸당 연산은 문제의 가정에 따라 O(1)이므로 시간 O(n²), 공간 O(n²). 두 행만 유지하면 공간은 O(n)으로 줄일 수 있다.

Q3
(10 points) Consider the following variation of the maximum flow problem: Each vertex
also has a capacity on the maximum flow that can enter it. Show that this problem can
be solved efficiently. You don’t need to analyze your algorithm.
한국어 풀이 (독립 검증)

정점 분할 환원. 원래 간선 (u,v)의 용량을 c(u,v), 정점 v의 용량을 c(v)라 하자. 각 정점에 v_in, v_out을 만들고 내부 간선 v_in → v_out의 용량을 c(v)로 둔다. 각 원래 간선 (u,v)는 u_out → v_in 용량 c(u,v)로 바꾼다. 그러면 v로 들어오는 유량은 내부 간선을 지나야 하므로 해당 정점 용량을 넘을 수 없다.

소스·싱크 주의. 원문의 “v로 들어오는 유량”을 문자 그대로 해석하면 싱크 t의 용량은 t_in → t_out을 지나게 하고 새 싱크를 t_out으로 두어 강제한다. 소스 s로 들어오는 유량은 s–t 유량값을 늘리지 않으며 순환 유량은 제거할 수 있으므로, 새 소스는 s_out으로 둔다. 따라서 이 문자 그대로의 해석에서는 c(s)가 소스에서 나가는 유량을 제한하지 않는다. 만약 수업에서 정점 용량을 “정점을 통과하는 총 유량”으로 정의해 소스 용량도 제한하려는 관례라면 새 소스를 s_in으로 두어 s_in → s_out 용량도 경로에 포함시킨다. 싱크 용량은 어느 해석에서든 위 분할로 처리한다.

정당성·복잡도. 변환 네트워크의 모든 s–t 경로는 제한 대상 정점의 내부 간선을 통과하므로 정점 용량 제약과 원래 간선 용량 제약이 정확히 표현된다. 반대로 원래의 허용 유량은 각 정점에서 유입·유출을 내부 간선으로 연결해 변환 네트워크의 유량으로 옮길 수 있다(소스의 들어오는 순환 유량은 제거 가능). 정점 수는 최대 2|V|, 간선 수는 |E|+|V|이므로 변환은 선형 시간이다. 이후 Edmonds–Karp 같은 다항 시간 최대 유량 알고리즘을 실행하면 된다.

Q4
(10 points) Suppose someone presents you with a solution to a max-flow problem on some
network. Give a linear time algorithm to determine whether the solution does indeed
give a maximum flow. You don’t need to analyze your algorithm.
한국어 풀이 (독립 검증)
  1. 가능 유량인지 확인. 모든 간선에 대해 0 ≤ f(e) ≤ c(e)인지 확인하고, 소스·싱크를 제외한 모든 정점에서 유입량과 유출량이 같은지 확인한다. 위반하면 최대 유량 해가 아니다.
  2. 잔여 그래프를 만든다. 정방향 잔여 용량은 c(e)-f(e), 역방향 잔여 용량은 f(e)이다.
  3. 증가 경로 검사. 잔여 그래프에서 BFS/DFS로 s에서 t에 도달 가능한지 확인한다. 경로가 있으면 더 유량을 보낼 수 있으므로 최대가 아니다. 경로가 없으면 최대 유량 정리에 의해 최대 유량이다.

정당성. 유량 제약을 만족하는 후보만 검사하며, 증가 경로의 존재와 최대 유량성은 최대 유량 정리에 의해 동치다. 복잡도. 제약 확인과 잔여 그래프 탐색은 합쳐서 시간 O(|V|+|E|), 공간 O(|V|+|E|).

Q5
(10 points) Prove the following: For any value α, no polynomial-time α-approximation
algorithm for the traveling salesman problem exists unless P = NP. You may use the
fact that Hamiltonian Cycle is NP-complete.
한국어 풀이 (독립 검증)

감소. Hamiltonian Cycle 인스턴스인 무방향 그래프 G=(V,E)를 받는다. 같은 정점 집합의 완전 가중 그래프를 만들고, G의 간선에는 가중치 1, G에 없는 쌍에는 M=αn+1을 부여한다(n=|V|, 통상적인 고정 근사비 α≥1을 가정). 이 구성은 다항 시간이다.

정당성. G에 해밀턴 사이클이 있으면 그 투어 비용은 n이다. 따라서 α-근사 알고리즘이 반환하는 투어 비용은 αn 이하이고, 가중치 M>αn인 비간선을 사용할 수 없다. 반환 투어의 모든 간선은 G의 간선이므로 해밀턴 사이클을 얻는다. 반대로 해밀턴 사이클이 없으면 모든 투어는 적어도 하나의 비간선을 사용하므로 비용이 적어도 M>αn이다. 출력 비용이 αn 이하인지로 Hamiltonian Cycle을 다항 시간에 판정할 수 있어 P=NP가 된다.

범위. 이는 일반 가중치 TSP에 대한 gap 감소다. 비간선 가중치가 삼각부등식을 만족한다고 주장하지 않으므로 metric TSP의 근사 불가능성 증명으로 그대로 쓰면 안 된다. α가 입력 크기에 따라 변하는 경우에도, α(n)이 다항 시간에 계산 가능하고 그 표현 길이가 입력 크기의 다항식으로 제한된다면(그래야 M=α(n)·n+1을 감소 과정에서 다항 시간에 구성할 수 있으므로) 같은 논증을 적용할 수 있다.

Q6
(10 points) Show that the following problem (called Maximum Common Induced
Subgraph) is NP-hard: Given two graphs G1 = (V1 , E1 ) and G2 = (V2 , E2 ) and a
budget b, the goal is to compute two sets of nodes V1′ ⊆ V1 and V2′ ⊆ V2 whose deletion
leaves at least b nodes in each graph, and makes the two graphs identical.
한국어 풀이 (독립 검증)

해석과 감소. 표준적인 Maximum Common Induced Subgraph 문제에서 “identical”은 두 유도 부분그래프가 동형(isomorphic)이라는 뜻으로 해석한다. Clique 인스턴스 (G,k)에서 G₁=G, G₂=K_k, b=k를 만든다. 1≤k≤|V(G)|인 인스턴스에 대한 다항 시간 감소다.

(⇒) G에 k-클리크 C가 있으면 G에서 V(G)\C를 삭제하고 K_k에서는 아무것도 삭제하지 않는다. 두 그래프에 각각 k개 정점이 남고 모두 K_k이므로 동형이다.

(⇐) 두 잔여 그래프가 동형이고 각각 적어도 k개 정점을 가져야 한다. 하지만 K_k에서 삭제 후 남는 정점 수는 k 이하이므로 정확히 k개가 남는다. 따라서 G 쪽에도 정확히 k개가 남고, 그 유도 부분그래프는 K_k와 동형, 즉 완전그래프다. 그러므로 G에는 k-클리크가 있다. 따라서 이 문제는 NP-hard다.

주의. 서로 다른 정점 집합에 대한 문자 그대로의 라벨별 그래프 동일성은 표준적인 동형 해석과 다르며, 위 감소가 그 별도 변형까지 증명한다고 주장하지 않는다.

Q7
(10 points) The Vertex Cover problem is defined as follows. Given a graph G = (V, E)
and an integer k, find a set X of k vertices such that, for any edge uv ∈ E, either u or v
is contained in X. Give any exact algorithm for this problem running in time f (k) · nO(1)
for some function f . You don’t need to analyze your algorithm.
한국어 풀이 (독립 검증)

분기 알고리즘. 먼저 정확히 k개를 요구하는 문제와 크기 최대 k인 Vertex Cover 판정의 차이를 처리한다. k<0 또는 k>|V|이면 정확히 k개를 고를 수 없으므로 실패한다. 그 외에는 아래의 분기 탐색으로 크기 ≤k인 커버를 찾는다.

VC(G, k):
    if E(G) is empty: return ∅
    if k = 0: return FAIL
    choose any edge (u,v) in E(G)
    C ← VC(G-u, k-1)
    if C ≠ FAIL: return C ∪ {u}
    C ← VC(G-v, k-1)
    if C ≠ FAIL: return C ∪ {v}
    return FAIL

C ← VC(G,k)
if C = FAIL: return NO
while |C| < k:
    add any vertex from V\C to C
return C

정당성. 어떤 vertex cover든 선택한 간선 (u,v)의 u 또는 v를 포함해야 한다. 따라서 두 분기는 모든 가능한 해를 포괄하며, 재귀는 선택한 정점을 제거하고 남은 간선들을 커버하도록 문제를 줄인다. 간선이 없어지면 현재 선택 집합은 커버다. 그러므로 알고리즘은 크기 ≤k인 커버가 있을 때만 성공한다. k≤|V|이면 그러한 커버에 아직 선택하지 않은 정점을 더해 정확히 k개로 패딩할 수 있고, 커버의 성질은 유지된다. 반대로 정확히 k개 커버가 있으면 크기 ≤k인 커버도 존재한다.

복잡도. 깊이는 k 이하, 각 단계에서 최대 두 분기이므로 시간 O(2^k(|V|+|E|)), 따라서 f(k)n^{O(1)} 꼴이다. 그래프 복사본을 재귀마다 저장하는 단순 구현의 공간은 O(k(|V|+|E|))이다.
