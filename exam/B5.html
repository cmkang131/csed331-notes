QE (2013) #4

볼록 다각형 의 꼭짓점 이 시계 방향으로 배열에 주어지고, 은 가장 왼쪽, 은 가장 오른쪽이며 인 모든 는 선분 위쪽에 있다. 직선 이 주어질 때 을 평행이동한 직선이 위에서 에 접하는 꼭짓점을 에 찾아라. ( 은 수직이 아니라고 하자.)

힌트 보기

위쪽 chain 은 시계 방향이므로 변의 기울기가 단조 감소한다. 의 기울기 에 대해 기울기가 이하가 되는 첫 변을 이분탐색.

정답 보기
  1. 의 기울기를 라 하자. 과 평행한 직선이 위에서 접하는 꼭짓점은 를 최대화하는 꼭짓점이다.
  2. 위쪽 chain 에서 변 의 기울기 는 가 늘수록 감소한다 (볼록, 시계 방향). 따라서 이면 이 보다 가 더 크고, 이면 작거나 같다. 값이 증가하다 감소하는 모양 (unimodal) 이다.
  3. lo = 1; hi = n
while lo < hi:
  mid = (lo + hi) / 2
  if slope(p[mid], p[mid+1]) > s: lo = mid + 1
  else: hi = mid
return p[lo]
  4. 시간 구간이 매번 절반이 되므로 . 최대값은 위쪽 chain 위에 있다: 각 에서 위쪽 chain 이 아래쪽 chain 보다 높기 때문.
