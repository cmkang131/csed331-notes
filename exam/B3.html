2021 Mid #2 (두번째 시험)

정수 개의 리스트 에서 이고 인 쌍 의 개수를 분할정복으로 효율적으로 구하고 running time 을 분석하라.

힌트 보기

merge sort 의 merge 단계에서 센다: 왼쪽 반 와 오른쪽 반 가 각각 정렬되어 있으면 와 사이의 쌍을 선형 시간에 셀 수 있다.

정답 보기
  1. 정렬된 (왼쪽 반), (오른쪽 반) 를 merge 하면서, 의 원소 를 꺼낼 때마다 그 시점에 이미 나간 원소의 수 를 더한다.
  2. Count(L):
  if |L| <= 1: return (L, 0)
  (A, cA) = Count(left half);  (B, cB) = Count(right half)
  c = cA + cB;  p = 0;  q = 0;  R = []
  while p < |A| or q < |B|:
    if p < |A| and (q == |B| or A[p] < B[q]):
      R.append(A[p]); p++
    else:
      c += p;  R.append(B[q]); q++       // 이미 나간 A 원소는 모두 < B[q]
  return (R, c)
  3. 정당성 는 일 때만 먼저 나가므로 이미 나간 원소는 현재 이하의 원소들보다도 작고 (즉 ), 아직 안 나간 원소는 . 따라서 와 짝이 되는 원소의 수가 정확히 .
  4. 시간 (직접 세면 ).
