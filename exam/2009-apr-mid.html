Q1
Given an array $A$ consisting of $n$ integers $A[1], A[2], \dots, A[n]$, you'd like to output a two-dimensional $n$-by-$n$ array $B$ in which $$B[i,j] = \begin{cases} A[i] + A[i+1] + \cdots + A[j] & \text{if } i < j, \\ 0 & \text{otherwise.} \end{cases}$$ Here's a simple algorithm to solve this problem. **Algorithm** *Add-ups* (* $A$: input array, $B$: output array. *) 1. **for** $i = 1, 2, \dots, n$ 2. $\quad$ **for** $j = i+1, i+2, \dots, n$ 3. $\quad\quad$ Add up array entries $A[i]$ through $A[j]$ 4. $\quad\quad$ Store the result in $B[i, j]$ - **(a) (5pts)** Give asymptotic upper bound($O(\cdot)$) and lower bound($\Omega(\cdot)$) on the running time of Algorithm *Add-ups* on an input of size $n$. - **(b) (5pts)** Give a different algorithm to solve this problem, with an asymptotically better running time.
Q2
Consider the problem of computing $N! = 1 \cdot 2 \cdot 3 \cdots N$. - **(a) (5pts)** If $N$ is an $n$-bit number, how many bits long is $N!$, approximately (in $\Theta(\cdot)$ form)? - **(b) (5pts)** Give an algorithm to compute $N!$ and analyze its running time, assuming that it takes $O(\log n)$ time for multiplying two $n$-bit numbers. *(인쇄 원문이 $O(\log n)$ — 그대로 옮김)*
주석: (b)의 O(log n) 곱셈 가정은 원문 그대로 [sic].
Q3
(10pts) Mergesort divides the input into two pieces of equal size; solves the two subproblems on these pieces separately by recursion; and then combines the two results into an overall solution. Thus the worst case running time, denoted by $T(n)$, on input instances of size $n$ satisfies the following recurrence relation. For some constant $c$, $$T(n) \le 2T(n/2) + cn$$ where $n > 2$, and $T(2) \le c$. Show that $T(n)$ is bounded by $O(n \log n)$, when $n > 1$, using the mathematical induction argument. (For simplicity, assume that $n$ is a power of 2.)
Q4
(10pts) We are given a sequence of $n$ distinct numbers $a_1, a_2, \dots, a_n$. We define a significant inversion to be a pair $i < j$ such that $a_i > 2a_j$. Give an $O(n \log n)$ time algorithm to count the number of significant inversions.
Q5
(10pts) Design a linear-time algorithm which, given an undirected graph $G$ and a particular edge $e$ in it, determines whether $G$ has a cycle containing $e$.
Q6
(10pts) Explain why the following statement is true. > Let $G$ be an arbitrary connected, undirected graph with a distinct cost $c(e)$ on every edge $e$. Suppose $e^*$ is the cheapest edge in $G$; that is, $c(e^*) < c(e)$ for every edge $e \ne e^*$. Then there is a minimum spanning tree $T$ of $G$ that contains the edge $e^*$.
Q7
(10pts) Suppose you are the CSE director of 해맞이한마당 at Postech (May 14–15, 2009.) Along the road ($M$ meters long) from the 78계단 to 학생식당입구, the possible sites for CSE stalls(노점) are given by numbers $x_1, x_2, \dots, x_n \in [0, M]$. If you place a CSE stall at location $x_i$, you're expected to make profit $r_i > 0$. Regulations imposed by SU require that no two of the stalls be within less than or equal to 10 meters of each other. Design an algorithm that finds a subset of sites so as to maximize CSE total profit, and analyze its running time. (Assume that sites are already sorted along the road.)
