최단 경로 문제와 DFS의 한계

  • distance — 두 노드 사이 shortest path의 길이 (경로 위 간선 길이의 합). 간선 길이는 3, 1, −2처럼 제각각
  • DFS 트리는 거리를 반영하지 못함 — 슬라이드 예: S와 C는 간선 하나인데 DFS 트리에선 S → A → B → C (3칸). C: 실제 1 vs 트리 3, E: 실제 1 vs 트리 2
  • 간선 길이가 전부 1이면 BFS가 최단 경로 (앞 장). 실로 노드를 연결한 물리 모델은 거리를 그대로 반영

길이가 정수일 때 — 두 가지 시도

  • 1차: dummy node — 길이 간선을 개의 dummy 노드로 바꾸고 BFS. 답은 맞지만 길이가 이면 dummy 세느라 시간을 다 씀. 정수가 아니거나 음수면 불가
  • 2차: alarm clock — alarm(s) = 0, 나머지 ∞. 시각 에 노드 에서 알람이 울리면 확정, 이웃 마다 alarm(v) = min{alarm(v), }. 가장 먼저 울리는 알람 찾기 = priority queue

Dijkstra가 맞는 이유

  • 핵심 관찰: → 최단 경로 = 이미 아는 최단 경로 + 간선 하나
  • known region (dist 확정된 노드): 에서 밖으로 나가는 단일 간선 확장 중 가장 짧은 것의 끝점이 다음 확정 노드
  • invariant: → 최단 경로는 보다 가까운 노드들만 지나감 — 간선 길이가 양수일 때만 성립
왜 더 짧은 다른 경로가 없는가 (증명)
  • → 의 다른 경로는 어딘가에서 처음으로 을 벗어남 (간선 , , )
  • 의 후보 거리는 확정된 노드까지의 최단 경로에 로 가는 간선 하나를 더한 길이 중 최솟값이고, 는 후보 거리가 가장 작은 노드이다. 따라서 까지의 경로 길이 ≥ 까지의 최단 거리 + ≥ 의 후보 거리 ≥ 의 후보 거리이다.
  • 이후 구간 길이 ≥ 0 (양수 간선) → 경로 전체 ≥ dist()

음수 간선과 Bellman-Ford

Dijkstra의 invariant(최단 경로는 보다 가까운 노드만 지남)가 음수 간선에서 깨짐 — 나중에 더 짧아질 수 있어서 최솟값 노드가 final인지 알 수 없고, priority queue를 쓸 수 없음.

  • update(u, v) — dist(v) > dist(u) + 이면 내리고 prev(v) = u. dist는 항상 과대평가이거나 정확 — update는 내리기만 하고 정답 밑으로는 안 내려감
  • update가 final 값을 주는 조건: 가 로 가는 최단 경로의 바로 앞 노드이고 dist(u)가 이미 정확
  • 최단 경로 의 성질: ① 모든 prefix 도 최단 경로 (아니면 dist(t)를 더 줄일 수 있음) ② simple (negative cycle이 없으니 cycle은 빼도 손해 없음) ③ 는 정확히 개 간선

Bellman-Ford

for i = 1 to |V| - 1
    for all e in E
        update(e)
  • 귀납: 모든 간선을 번 update하면 간선 개짜리 최단 경로의 dist가 final. simple path는 간선 개 → 라운드면 전부 final. 간선을 도는 순서는 정답에 영향 없음
  • 시간 — Dijkstra보다 느린 대신 음수 간선 가능 (negative cycle 제외)

DAG — 위상 순서와 최단 경로

  • topological ordering (위상 순서) — 모든 간선 에서 가 보다 앞에 오는 노드 순서. 줄로 펴면 모든 간선이 왼쪽 → 오른쪽
  • DAG ⇔ topological ordering이 존재. 순서는 유일하지 않음
  • 만드는 법 ① source(in-degree 0)를 간선과 함께 제거하는 것을 반복 — 남은 그래프도 DAG ② DFS post 내림차순 (앞 장)
  • 슬라이드 그래프 (A→B 4, A→C 2, A→D 3, C→B 1, C→D −4, C→E 5, B→D 2, B→E 3)의 in-degree 추적: 0단계 A 0, B 2, C 1, D 3, E 2 → A 제거 → C 제거 → B 제거 → E (또는 D) 제거 → D 제거. 제거 순서 A, C, B, E, D
  • 순서는 유일하지 않음 — D, E를 맞바꾼 A, C, B, D, E도 가능 (이 그래프는 정확히 2개). DFS post 내림차순(이웃은 알파벳 순)으로도 A, C, B, E, D가 나옴 (post: A 10, C 9, B 7, E 6, D 4)
  • cycle이 있으면 제거하다 막힘 — 슬라이드 17 그래프는 모든 노드 in-degree ≥ 1이라 첫 단계부터 제거 불가
  • in-degree 카운터를 갱신하며 제거하면 . DAG 여부 자체는 DFS back edge로 확인

연습문제

문제 1

슬라이드 22의 방향 그래프에서 출발점을 B로 바꿔 Dijkstra를 돌리고 확정 순서와 dist를 구하시오. A는 어떻게 되는가.

힌트 보기

deletemin으로 가장 작은 노드를 꺼내 확정하고 나가는 간선만 update. 간선은 화살표 방향으로만 따라감 — 들어오는 간선이 없는 노드는 영원히 ∞.

정답 보기

개념은 위 힌트 참고.

  1. B의 나가는 간선: B→C 3, B→D 2, B→E 3. deletemin B(0) → C = 3, D = 2, E = 3
  2. deletemin D(2): 나가는 간선 없음 → 그대로
  3. deletemin C(3): C→B, C→D, C→E 모두 더 길어 갱신 없음
  4. deletemin E(3): E→D = 3 + 1 = 4 > 2 → 갱신 없음
  5. A로 들어오는 간선이 없음 → dist(A) = ∞ (도달 불가)

힌트 보기
  1. B→C −3과 C→B −3이 왕복 cycle을 만듦
  2. 라운드 는 라운드 의 값만 읽어 update
  3. 번째 라운드에도 값이 줄어들면 negative cycle
정답 보기

개념은 위 힌트 참고.

  1. B→C→B 길이 = −3 + (−3) = −6 → negative cycle
  2. 라운드별 B: ∞, 4, −1, −2, −7, −8 (라운드 0 → 5)
  3. 라운드별 C: ∞, 2, 1, −4, −5, −10
  4. 5번째(= ) 라운드에도 값이 줄어듦 → negative cycle 검출

문제 3

힌트 보기
  • 순서상 앞 노드에서 뒤 노드로만 감
  • 출발점보다 순서가 앞인 노드는 도달 불가
  • dist = ∞인 노드는 처리해도 갱신 없음
정답 보기

개념은 위 힌트 참고.

  1. A 처리: dist(A) = ∞라 건너뜀 (A는 C보다 앞이라 도달 불가)
  2. C 처리: B = 1, E = 5, D = −4
  3. B 처리: E = 1 + 3 = 4 (D는 1 + 2 = 3 > −4 → 그대로)
  4. E, D 처리: 나가는 간선 없음 → 그대로
  5. E의 prev는 B (C→B→E = 4 < 직접 5)
